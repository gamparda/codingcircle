# Asset sources

## Unit character sheets

The four source sprite sheets under `assets/source/role_sheets/` were supplied directly by the project owner on 2026-08-29 for use in this game:

- `tanker_sheet.jpg`
- `healer_sheet.png`
- `archer_sheet.png`
- `swordsman_sheet.png`

Transparent gameplay sprites under `assets/units/` are derived from those sheets by `tools/extract_sprites.py`.

Before public redistribution or commercial use, the repository owner should confirm that the original artwork license permits it.
