# Background Assets

배경 이미지는 추후 제공 예정입니다.

권장 파일명:

- `01-dungeon.*` — 1~10층 무너진 던전
- `02-forest.*` — 11~20층 뒤틀린 숲
- `03-beach.*` — 21~30층 저주받은 해변
- `04-desert.*` — 31~40층 죽음의 사막
- `05-snowfield.*` — 41~50층 얼어붙은 설원
- `06-volcano.*` — 51~60층 화산지대
- `07-rift.*` — 61~70층 차원의 틈새
- `08-hell.*` — 71~80층 지옥
- `09-heaven.*` — 81~90층 천국
- `10-ender.*` — 91~100층 엔더
