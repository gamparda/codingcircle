# 하늘을 삼킨 탑

브라우저에서 바로 실행되는 100층 턴제 RPG입니다.

## 실행 방법

1. GitHub에서 ZIP 다운로드
2. 압축 풀기
3. `index.html` 더블클릭

별도 설치 없이 실행됩니다.

## 게임 목표

세상 한가운데 솟아난 탑의 꼭대기에서 검은 별빛이 떨어지고 있습니다.
플레이어는 이름 없는 모험가가 되어 100층까지 올라가 탑의 핵을 파괴해야 합니다.

하지만 탑을 오를수록 밝혀집니다.
이 탑은 단순한 마물의 소굴이 아니라, 오래전 멸망한 문명 **아르카론**이 만든 봉인 장치였다는 것을.

## 플레이 방식

- 턴제 전투
- `공격`, `스킬`, `포션` 사용 가능
- 10층마다 보스 등장
- 보스 처치 시 석판 기록 공개
- 100층 엔더 드래곤 처치 시 엔딩 도달

## 초반 장비

1~5층까지는 **초보자 방망이**를 사용합니다.
5층을 넘기면 아래 무기 중 하나를 선택합니다.

| 무기 | 특징 |
|---|---|
| 한손검 | 균형형. 막기 확률 30% |
| 쌍검 | 낮은 공격력, 빠른 공속. 초반 선공 유리. 막기 확률 40% |
| 대검 | 높은 공격력, 느린 공속. 막기 확률 25% |
| 마법 지팡이 | 높은 공격력. 막기 없음. 보호막으로 피해 감소 |
| 활 | 적당한 공격력, 확정 선공권. 막기 없음 |

## 상점

각 10층 구간마다 기본적으로 두 번 상점이 열립니다.

- 중간 보급 상점
- 보스 직전 상점

상점에서 할 수 있는 것:

- 포션 구매
- 무기 강화
- 최대 HP 강화

## 층 구성

| 층 | 지역 | 잡몹 | 보스 |
|---|---|---|---|
| 1~10 | 무너진 던전 | 고블린 | 던전 골렘 |
| 11~20 | 뒤틀린 숲 | 늑구 | 붉은 눈의 알파늑대 |
| 21~30 | 저주받은 해변 | 소라게 | 심해 메갈로돈 |
| 31~40 | 죽음의 사막 | 미라 | 데스웜 |
| 41~50 | 얼어붙은 설원 | 설원 엘프 | 예티 |
| 51~60 | 화산지대 | 마그마골렘 | 용암 드래곤 |
| 61~70 | 차원의 틈새 | 마법사 | 검은 마법사 |
| 71~80 | 지옥 | 악마 | 마왕 바알 |
| 81~90 | 천국 | 천사 | 대천사 |
| 91~100 | 엔더 | 심연 덩어리 | 엔더 드래곤 |

```text
├── docs/story.md    # 전체 스토리 문서
└── assets/          # 추후 이미지 추가 위치
```
