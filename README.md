# 하늘을 삼킨 탑

100층 탑을 오르며 검은 별빛의 근원을 파괴하는 판타지 RPG 기획 레포입니다.

기존 파일은 모두 제거했고, 현재 레포는 새 게임 콘셉트/층 구성/스토리/무기 시스템을 기준으로 다시 정리했습니다.

## 기본 설정

세상 한가운데, 어느 날 거대한 탑이 솟아났다.
탑의 꼭대기에서는 매일 밤 검은 별빛이 떨어지고, 그 빛에 닿은 땅은 조금씩 생명을 잃어간다.

왕국은 수많은 모험가를 탑으로 보냈지만, 누구도 40층 이상에서 돌아오지 못했다.

플레이어는 이름 없는 모험가로 시작한다.
목표는 단순하다.

**100층까지 올라가 탑의 핵을 파괴하고, 세상을 죽이는 검은 별빛을 멈추는 것.**

하지만 올라갈수록 밝혀진다.
이 탑은 단순한 마물의 소굴이 아니라, 오래전 멸망한 문명 **아르카론**이 만든 봉인 장치였다는 것을.

## 진행 구조

- 총 100층
- 10층 단위로 지역/몬스터/보스 변경
- 각 지역 보스 처치 시 석판 조각 획득
- 석판은 탑의 정체와 아르카론의 멸망 이유를 밝히는 핵심 장치
- 100층에서 엔더 드래곤과 전투 후 탑의 핵과 마주함

## 초반 장비 지급

1~5층까지는 **초보자 방망이**를 지급합니다.
5층 이후 아래 무기 중 하나를 선택합니다.

| 무기 | 특징 |
|---|---|
| 한손검 | 균형형. 초보 친화적. 공격력/공속/방어가 안정적이며 막기 확률 30% |
| 쌍검 | 낮은 공격력, 빠른 공속. 초반부 거의 확정적인 선공권. 막기 확률 40% |
| 대검 | 높은 공격력, 느린 공속. 초반부 거의 확정적인 후공권. 스탯 관리에 따라 후반 변동. 막기 확률 25% |
| 마법 지팡이 | 높은 공격력, 적당한 공속. 막기 없음. 대신 보호막 스킬로 확정 방어 가능하나 피해 감소만 적용 |
| 활 | 적당한 공격력, 확정 선공권. 막기 없음 |

## 상점 배치

1~10층 구간 기준:

- 5층 클리어 후 상점 1회
- 9층 클리어 후 보스층 전 상점 1회

이후 구간에서도 같은 패턴을 기본으로 사용합니다.

- 각 구간 중간층 클리어 후 보급 상점
- 보스 직전층 클리어 후 보스 대비 상점

## 층 구성 요약

| 층 | 지역 | 잡몹 | 보스 |
|---|---|---|---|
| 1~10 | 무너진 던전 | 고블린 | 던전 골렘 |
| 11~20 | 뒤틀린 숲 | 늑구 | 붉은 눈의 알파늑대 |
| 21~30 | 저주받은 해변 | 소라게 | 심해 메갈로돈 |
| 31~40 | 죽음의 사막 | 미라 | 데스웜 |
| 41~50 | 얼어붙은 설원 | 설원 엘프 | 예티 |
| 51~60 | 화산지대 | 마그마골렘 | 용암 드래곤 |
| 61~70 | 차원의 틈새 | 마법사 | 검은 마법사 |
| 71~80 | 지옥 | 악마 | 마왕 바알 |
| 81~90 | 천국 | 천사 | 대천사 |
| 91~100 | 엔더 | 심연 덩어리 | 엔더 드래곤 |
