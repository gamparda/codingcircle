# Cat War 밸런스 1차 조정 결과

2026년 10월 3일 · 기준 커밋 `c195ef4` · Godot 4.7.2

실제 전투 코드와 AI를 화면·대기 없이 실행해 **총 49,212경기**의 완료 기록을 확보했습니다. 탐색 실험과 교정한 구매 봇의 최종 비교를 분리했습니다.

최종 비교는 변경 전후 각각 **PvP 3,570경기 + AI 1~8단계 1,680경기**, 합계 **10,500경기**입니다. 모든 35개 유닛 덱과 순환·전술·가중치 구매를 같은 시드로 돌리고 진영을 바꿨습니다. 서버와 같은 30Hz 계산으로 전후 각각 528경기를 추가 확인했습니다.

## 반영한 조정

| 유닛 | 비용 이전 → 현재 | 공격력 이전 → 현재 |
|---|---:|---:|
| 탱커 | 35 → 45 | 2 → 2 |
| 검사 | 30 → 30 | 10 → 11 |
| 궁수 | 45 → 50 | 15 → 14 |
| 마법사 | 45 → 25 | 0 → 0 |
| 광전사 | 40 → 40 | 13 → 13 |
| 흑마법사 | 45 → 35 | 1 → 4 |
| 네크로맨서 | 100 → 110 | 2 → 2 |

마법사의 지원 주기는 7초에서 4초로 줄였습니다. 공격 속도 +3% 누적과 최대 +30%는 유지합니다. 동시 공격을 함께 판정해 유닛 배열 순서가 먼저인 쪽만 치명타를 넣던 문제를 수정했고, 양쪽 기지가 같은 시점에 파괴되면 무승부가 됩니다.

AI는 공격 유닛 없는 4단계와 보호받는 소환 병력에 과도하게 의존하던 6단계 구성을 조정했습니다. 필요한 유닛 직전에 싼 카드로 자원을 써버리는 구매를 고쳤고, 단계별 병력·수입·구매 주기를 실험 결과에 맞췄습니다.

## 최종 대전 데이터

승점률은 완료 경기의 승리=1, 무승부=0.5이며 시간 초과는 제외합니다. 아래 수치는 해당 유닛을 포함한 **덱 전체**의 결과입니다.

| 포함 유닛 | 변경 전 | 변경 후 |
|---|---:|---:|
| 탱커 | 66.4% | 62.9% |
| 검사 | 46.7% | 48.2% |
| 궁수 | 60.6% | 65.0% |
| 마법사 | 35.0% | 39.5% |
| 광전사 | 51.6% | 48.5% |
| 흑마법사 | 35.1% | 42.7% |
| 네크로맨서 | 54.5% | 43.3% |

파랑 진영 승점률은 **50.0% → 50.3%**입니다. PvP 600초 초과는 **16 → 0건**, 경기 시간 중앙값은 **92.7 → 102.9초**입니다.

탱커·궁수를 포함한 덱의 우세는 남아 있습니다. 유닛 단독 효과와 포함 덱 승점률은 다르며, 조합·구매 정책·건설 선택을 함께 봐야 합니다. 지원 유닛을 직접 피해량만으로 평가하지 않습니다.

## AI 난이도 곡선

실제 플레이어 위치인 파랑 진영만 집계했습니다. 단계마다 35개 덱 × 3개 구매 정책 = 105경기이고, 직전 단계까지의 성장 보너스를 적용했습니다.

| 단계 | 이전 플레이어 승점률 | 조정 후 | 이전 시간 초과 | 조정 후 시간 초과 |
|---|---:|---:|---:|---:|
| 1 | 85.7% | 100.0% | 0 | 0 |
| 2 | 82.9% | 100.0% | 0 | 0 |
| 3 | 81.7% | 69.5% | 12 | 0 |
| 4 | 95.0% | 64.8% | 25 | 0 |
| 5 | 72.4% | 61.0% | 0 | 0 |
| 6 | 4.8% | 47.6% | 0 | 0 |
| 7 | 58.1% | 30.5% | 0 | 0 |
| 8 | 3.9% | 26.7% | 3 | 0 |

1~2단계는 입문용으로 쉽게 두고, 3단계부터 8단계까지 자동 대전의 플레이어 승점률이 점차 낮아지는 곡선을 확보했습니다. 이전 6단계의 급격한 난이도 상승과 4단계의 긴 정체가 줄었습니다.

## 검증과 재현

- 30Hz 검증: 전후 1,056경기. 조정 후 PvP 파랑 승점률 50.0%.
- 조정 후 30Hz 표본 528경기 중 0.1초 계산과 승패가 달라진 경기는 57건입니다. 전체 순위와 단계별 표는 35개 덱 전체 탐색 결과로 읽고, 이 표본으로 순위를 대신하지 않습니다.
- 전투·소환·저주·성장·보고서·구매 정책·동시 공격 회귀 검증 통과. 실제 오프라인 AI 시작과 로컬 ENet 두 클라이언트 대전도 통과.
- 분석기의 미완료·중복·진영 교환 누락·혼합 규칙·다른 구매 봇/시간 제한 비교 거부 등 8개 데이터 검증 통과.
- 관측기 보완 후 120경기를 재실행해 승패·시간·권위형 전투 보고서가 모두 일치함을 확인.
- 원본 JSONL, 경기 CSV, 35개 덱의 상세 분석, SHA-256 목록과 실행 소스 스냅샷은 첨부 데이터 압축 파일에 보관.

자동 대전은 실제 인간 승률·재미·초보자 반응 속도를 측정하지 않습니다. 모든 유닛 덱 접근과 단계-1 성장을 가정하므로 실제 해금 경로와도 다릅니다. 다음 플레이 테스트에서는 탱커+궁수의 지속 우세, 초보자의 첫 두 단계, 지원 덱의 체감 성능을 확인하는 것이 좋습니다.
