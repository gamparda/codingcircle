- 가져오기 성공 후 조건을 초기화해 새 기록을 표시한다. 새 화면의 알림 칸을 사용하고 성공 안내에 기존 보관함 경고를 함께 남긴다. 실패는 조건을 유지한다.

- 테스트 추가·수정·실행, 게임 실행·렌더링은 하지 않았다. 실제 표시·조작·로드 검증은 외부 스크립트에 맡긴다.
- 호환성 변경: 없음. RPC 시그니처·세이브·서버 파일 형식·버전 번호·release.json·CHANGELOG·PatchNotes는 변경하지 않았다. Git 명령은 실행하지 않았다.
- 다음 후보: 도전 기록에서 보관한 전투 리플레이로 이동하는 흐름, 사본 복구 전후 캠페인·덱 변경의 상세 비교, 온라인 리플레이 코드 요청 중 중복 클릭·응답 화면 수명 관리.

## 2026-10-13 — 리플레이 선택 구간 클립 공유

- 이번 주제: 시작·끝으로 지정한 리플레이 구간을 정확한 클립으로 복사하고, 공유할 범위와 재생 안내를 명확히 한다.
- 시작 상태: Git 명령 없이 인덱스·추적 파일 내용 해시와 압축된 HEAD·인덱스 루트 트리를 읽어 비교했다. 미완료 변경·새 소스·문서는 없었다.
- 최근 3회차와 아카이브의 다음 후보를 읽고, 남아 있던 선택 구간 자체의 클립 공유를 선택했다.
- 확인한 문제: 시작·끝 지점을 정해도 기존 클립 복사는 가까운 명장면 주변을 공유해 지정한 교전 범위와 달랐다.
- 지정 구간이 완성되면 클립 복사가 구간 복사로 바뀐다. 재생 위치가 범위 밖이어도 지정한 시작·끝을 그대로 공유한다.
- 시작만 지정한 상태는 복사를 비활성화하고 끝 지정이나 구간 해제를 안내한다. 반복 재생을 켜지 않아도 구간을 공유한다.
- 상단 패널에 시작·끝·길이와 다음 조작을 표시한다. 구간 해제는 지점·집계 사본·반복을 함께 지우고 복사 버튼으로 초점을 옮긴다.
- 공유 범위 생성은 잘못된 전투 데이터·음수 시작·역전/빈 범위·기록 끝 초과를 거절한다. 0틱 기록으로 유효하지 않은 클립을 만들지 않는다.
- 기존 clip 필드와 공유 텍스트를 재사용한다. 시작 상태를 재현할 전체 명령·설정·결과·모든 메모를 포함하고 원본과 로컬 파일은 수정하지 않는다.
- 구간을 지정하지 않으면 가까운 명장면 또는 현재 위치 주변을 복사하는 기존 흐름을 유지한다. 앞뒤 10초와 명장면 탐색 거리를 기록 주파수로 계산한다.
- 확인한 추가 문제: 한 프레임에 여러 틱을 진행한 뒤에야 클립 끝을 확인해 배속에서 끝을 넘겼다. 매 틱 끝 경계를 확인하고 해당 틱에서 일시정지한다.
- 클립 안으로 다시 탐색하면 끝 정지를 다시 준비하고, 끝 이후 탐색이나 끝에서 재생은 이어 보기를 허용한다. 탐색·끝 정지 시 누적 재생 시간을 비운다.
- 사용자가 켠 구간 반복은 클립의 기본 끝 정지보다 우선한다. 처음부터는 기존처럼 클립 시작으로 돌아간다.
- 기록 끝에서 시작 지정·기록 끝을 넘는 끝 지정을 거절한다. 클립 제목 툴팁에도 범위·길이·이어 보기 방법을 안내한다.
- 알림을 보관·구간 패널 아래로 옮겨 가리지 않도록 했다. 새 해제 버튼 높이는 58이며 기존 하단 버튼·전투 요약 모달 흐름을 유지한다.
- README에 공유·가져오기·전체 기록 포함 범위를 설명했다. 이전 1회차를 아카이브로 옮기고 최근 3회차만 남겼다.
- 검토: 클립 검증·공유/가져오기 호출·틱 진행·탐색·반복·재시작·메모 보관·모달 차단과 변경 내용을 소스로 검토했다. 테스트 추가·수정·실행과 게임 실행·렌더링은 하지 않았으며 실행 검증은 외부 스크립트에 맡긴다.
- 호환성 변경: 없음. RPC 시그니처·세이브·서버 파일 형식·버전 번호·release.json·CHANGELOG·PatchNotes는 변경하지 않았다. Git 명령은 실행하지 않았다.
- 다음 후보: 도전 기록에서 보관한 전투 리플레이로 이동하는 흐름, 사본 복구 전후 캠페인·덱 변경의 상세 비교, 공유 클립 목록의 구간 길이 표시와 범위 검색.

## 2026-10-13 — 진행도 사본 검색·정렬과 선택 삭제

- 이번 주제: 많은 진행도 사본을 검색·정렬하고, 내용 확인 후 선택한 사본만 안전하게 정리한다.
- 시작 상태: Git 명령 없이 인덱스·추적 파일 내용 해시와 HEAD·인덱스 루트 트리를 비교했다. 미완료 변경·새 소스·문서는 없었다.

- 확인한 문제: 긴 드롭다운을 훑어 사본을 찾았고 불필요한 사본은 저장 폴더에서 수동으로 삭제해야 했다.
- 닉네임·UTC 보관 날짜·파일명·진행도 요약 검색을 추가했다. 공백으로 나눈 검색어가 모두 포함된 사본만 표시한다.

- 표시 수와 읽을 수 있는 전체 사본 수를 안내한다. 검색 결과 없음과 복구 가능한 사본 없음은 구분한다.
- 초기화는 검색과 정렬을 되돌린다. 검색·정렬 변경과 새로고침에도 선택한 파일 경로를 유지한다.
