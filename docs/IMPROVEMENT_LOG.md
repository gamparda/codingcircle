# 프로젝트 개선 기록

## 2026-10-14 — 전투 스탯의 양쪽 출전 덱·성장 수치 비교

- 이번 주제: 스탯 창에서 내 덱·상대 덱·공통/전용 구성을 선택하고 진영별 성장 수치를 비교하며, 온라인은 이미 받은 출전 정보만 사용한다.
- 시작 상태: Git 명령 없이 인덱스·추적 파일의 원본/LF 해시와 HEAD/인덱스 트리 해시를 직접 비교했다. 미커밋 변경·충돌·미추적 소스·문서가 없어 중단 작업은 없었다.
- 최근 3회차·다음 후보와 아카이브 주제를 읽고 양쪽 출전 덱 비교를 선택했다. 소스 수정 전에 이번 주제를 한 줄 먼저 기록했다.
- 확인한 불편: 상대 덱의 병력·구조물만 고르거나 공통·전용 구성을 구분할 수 없었고, 성장 수치는 내 진영 기준으로만 표시됐다.
- 진영 선택에 내 진영·상대 진영·양쪽 비교·공통 출전·내 전용 출전·상대 전용 출전을 추가했다. 관전에서는 블루·레드 기준으로 표시한다.
- 기존 출전 덱만 체크를 내·상대·양쪽에 맞춰 적용한다. 공통·전용 선택은 출전 구성으로 한정하며 기존 체크 상태와 검색어는 유지한다.
- 카드 제목에 양쪽·내·상대 출전 여부를 표시한다. 네크로맨서의 해골은 소환으로 구분하고 양쪽 구성 필터에 포함한다.
- 검색과 무관한 공통·전용 구성 개수를 분류별로 표시한다. 병력 개수에는 소환 병력도 포함한다고 안내해 덱 슬롯 수로 오인하지 않게 한다.
- 오프라인 양쪽 덱·성장 단계는 실제 모델에서 읽는다. 캠페인·도전·드래프트·고스트·되감기 실험의 구성을 따로 추정하지 않는다.
- 양쪽 병력 수치가 같으면 하나로 표시하고 다르면 같은 카드에서 진영별로 보여 준다. 미출전 진영의 값은 참고용으로 명시한다.
- 기존 병력 설명 생성 함수·성장 보너스 함수를 재사용한다. 일시적인 지원·장판 효과를 제외한 기준 수치임을 안내하며 밸런스는 바꾸지 않는다.
- 전투 규칙에 오프라인 양쪽 진영의 실제 기지 최대 체력·자원 회복·한도·병력 성장률을 각각 표시한다.
- 온라인 방 상태의 플레이어 순서는 서버 진영 배정 순서와 대조했고, 플레이어는 자기 ID·진영이 맞는 진행 중/종료된 방 정보만 사용한다.
- 상대 덱 정보가 없는 연결에서는 비교 선택을 비활성화하고 이유를 안내한다. 관전의 미확인 덱을 개인 저장 덱으로 대체하지 않으며, 기존 방 연결의 내 덱은 제출한 클라이언트 덱을 사용한다.
- 진영 선택 메뉴에 터치 간격과 Tab 초점을 제공한다. Esc는 열린 선택 메뉴부터 닫고 다음 입력으로 스탯 창을 닫는다. 자동 정지 때 선택 메뉴를 닫아 정지 안내를 가리지 않게 한다.
- README를 갱신하고 오래된 1회차를 아카이브로 옮겨 최근 3회차만 남겼다. 소스로 진영 배정·정보 부재·필터 조합·성장 산식·팝업과 모달 입력 우선순위를 검토했다.
- 테스트는 추가·수정·실행하지 않았고 게임 실행·렌더링도 하지 않았다. 실제 로드·진영별 필터·관전·기존 방 연결·팝업·자동 정지 복귀 검증은 외부 스크립트에 맡긴다.
- 호환성 변경: 없음. RPC 시그니처·세이브·서버 파일 형식과 버전 번호·release.json·CHANGELOG·PatchNotes를 유지했다. Git 명령은 실행하지 않았다.
- 다음 후보: 복구 비교에서 변경된 항목만 탐색하는 흐름, 보관함의 선택 검색어를 카드 밖에서도 개별 해제하는 조작, 스탯 창의 검색·진영 선택을 같은 전투에서 다시 열 때 유지하는 흐름.

## 2026-10-14 — 전투 스탯 분류·검색과 스크롤 탐색

- 이번 주제: 전투 스탯을 병력·구조물·전투 규칙으로 나누고 이름·효과 검색과 출전 덱 필터, 줄바꿈·키보드 탐색으로 긴 설명을 쉽게 읽는다.
- 시작 상태: Git 명령 없이 인덱스와 추적 파일의 원본/LF 해시, HEAD/인덱스 트리 해시를 직접 비교했다. 미커밋 변경·충돌·미추적 소스·문서가 없어 중단 작업은 없었다.
- 최근 3회차·다음 후보와 아카이브 주제를 읽었다. 전투 중 실제로 설명을 찾는 흐름을 우선하고 소스 수정 전에 주제를 한 줄 기록했다.
- 확인한 불편: 병력 카드는 너비 455의 고정 2열이었고, 구조물·전장 설명은 스크롤 밖의 줄바꿈 없는 텍스트였다. 원하는 항목만 찾거나 온라인에서 Esc로 닫기 어려웠다.
- 병력·구조물·전투 규칙 분류 버튼을 추가했다. 검색칸·필터·닫기는 스크롤 밖에 유지하고 설명 카드만 스크롤한다.
- 이름과 설명의 부분 검색을 제공한다. 띄어쓴 단어를 모두 포함하는 항목만 표시하며 검색 지우기·결과 개수·빈 결과 안내를 제공한다.
- 내 출전 덱만 필터와 출전 구성 표시를 추가했다. 로컬 전투는 현재 모델의 구성, 온라인은 전투 진입 시의 구성, 관전은 블루 구성을 사용한다.
- 네크로맨서가 출전한 덱에서는 소환 전용 해골 설명도 함께 표시한다. 분류 전환 시 검색어·덱 필터를 유지하고 전투 규칙에는 덱 필터를 적용하지 않는다.
- 구조물별 비용·체력·종류 한도·진영 전체 한도를 카드로 분리했다. 늪 감속·반경·수명, 포탑 공격·DPS·간격·사거리, 발전기 수입·후방 제한을 안내한다.
- 기존 병력 스탯 생성 함수와 전장·지원 설명을 재사용했다. 수치는 모델 상수·데이터에서 읽으며 전투 규칙이나 밸런스는 바꾸지 않는다.
- 기본 규칙과 내 진영의 성장 반영 수치를 구분한다. 오프라인에서는 실제 모델의 기지 최대 체력·자원 회복·한도와 병력 성장률을 별도 카드에 표시한다.

## 2026-10-14 — 오프라인 전투 일시정지와 앱 이탈 보호

- 이번 주제: 캠페인을 포함한 오프라인 전투에 버튼·Space 일시정지, 스탯 확인 중 정지, 앱 이탈 시 자동 정지와 명시적 재개를 제공한다.
- 시작 상태: Git 명령 없이 인덱스·추적 파일의 원본/LF 해시와 HEAD/인덱스 트리 해시를 직접 비교했다. 미커밋 변경·충돌·미추적 소스·문서가 없어 중단 작업은 없었다.
- 최근 기록·다음 후보와 아카이브 주제를 확인했다. 보관함 개선이 집중되어 있어 실제 플레이 중 자리를 비우거나 설명을 읽을 때의 전투 보호를 선택했고 소스 수정 전에 주제를 기록했다.
- 확인한 불편: 캠페인에는 일시정지가 없었고 스탯 창을 읽는 동안에도 전투가 계속됐다. 창 이탈·모바일 백그라운드 전환에도 전투가 진행될 수 있었다.
- 캠페인 전투 상단에 일시정지 버튼을 추가했다. 기존 연습·도전·드래프트·고스트·되감기 실험 버튼도 같은 일시정지 안내 창을 사용하며 Space로 조작한다.
- 안내 창은 계속하기 버튼과 Space/Enter로 재개한다. 버튼은 놓을 때 실행하고 높이 58을 적용하며 Tab 초점과 구매 키 입력이 뒤쪽 화면으로 넘어가지 않게 한다. F11 조작은 유지한다.
- 창의 앱 초점 이탈·모바일 앱 정지 알림에서 자동 정지한다. 돌아와도 직접 재개해야 하며 중복 알림은 같은 안내 창을 유지한다. 백그라운드에서 시작한 오프라인 전투도 정지한다.
- 오프라인 스탯·기존 확인창·요약 창이 열리면 로컬 시뮬레이션을 진행하지 않는다. 스탯 창에는 정지 안내와 닫기/Esc 조작을 제공하며 닫은 뒤 초점을 스탯 버튼으로 돌린다.
- 정지 중 전투 시간·자원 회복·모델의 생산 쿨다운과 AI 명령·전장 애니메이션을 멈춘다. 재개 첫 프레임의 경과 시간을 버려 백그라운드 체류 시간을 따라잡지 않는다.
- 기존 고정 30Hz 기록과 틱 잔여 시간은 유지한다. 정지 중 기록 틱을 추가하지 않고 배속·무한 자원·상대 덱 설정과 연습 도구 사용 판정은 바꾸지 않는다.
- 구매 카드·단축키·전장 설치는 같은 정지 상태를 확인한다. 선택한 구조물은 정지 사유만으로 해제하지 않으며 재개 후 기존 자원·설치 한도로 다시 판단한다.
- 진행 중인 터치 설치는 정지 시 중단한다. 앱 복귀 직후 손가락을 놓아 뜻하지 않은 설치가 일어나지 않으며 선택한 구조물로 새 동작을 시작할 수 있다.
- 앱 이탈 전 스탯·확인창과 키보드 초점을 유지한다. 자동 정지를 해제해도 원래 창이 열려 있으면 전투는 계속 정지하며 원래 창을 닫아야 진행된다.
- 화면 교체 시 정지 창을 숨기고 해제하며 이전 초점 참조를 비운다. 종료 결과·기지 붕괴 연출 중에는 새 정지를 만들지 않으며 온라인 대전·관전·서버 처리는 계속 진행한다.
- README를 갱신하고 가장 오래된 1회차를 아카이브로 옮겨 최근 3회차만 남겼다. 소스로 시작·정지·재개·화면 교체·구매 차단·기록 틱·연출과 모달 초점 경로를 검토했다.
- 테스트는 추가·수정·실행하지 않았고 게임 실행·렌더링도 하지 않았다. 실제 로드·창 전환·모바일 복귀·키보드·터치·리플레이 재현·기존 기능 검증은 외부 스크립트에 맡긴다.
