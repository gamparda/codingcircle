# 프로젝트 개선 기록

## 2026-10-13 — 최근 온라인 전투 검색·결과 필터

- 이번 주제: 최근 온라인 전투를 보관 날짜·공유 코드·병력 이름과 결과로 빠르게 찾고 새로고침 때 탐색 상태를 유지한다.
- 시작 상태: Git 명령 없이 인덱스·추적 파일 해시와 HEAD·인덱스 루트 트리를 비교해 미커밋 변경이 없음을 확인했다. 최근 3회차와 아카이브의 다음 후보에서 날짜·덱·결과 탐색을 선택했다.
- 확인한 문제: 최신 공개 전투를 카드마다 읽어야 했고 특정 날짜·병력·승리 진영의 전투를 좁힐 수 없었다.
- 검색 입력과 빠른 대전/방 대전 종류 필터, 블루 승/레드 승/무승부 결과 필터를 추가했다.
- 공유 코드·양쪽 병력의 게임 내 이름과 영문 ID·전투 종류·결과·전투 시간을 검색한다.
- UTC 보관 날짜는 YYYY-MM-DD와 YYYYMMDD를 모두 지원한다. 추정 시각도 포함하고 미상은 미상으로 검색하며 코드나 전투 길이로 날짜를 추정하지 않는다.
- 공백으로 나눈 검색어가 모두 포함된 카드만 표시한다. 코드·영문 ID는 대소문자를 구분하지 않는다.
- 검색 대상이 조회된 최근 공개 목록임을 안내한다. 더 오래된 보관 전투까지 검색한다고 오인하지 않도록 개수 툴팁과 빈 결과 안내를 제공한다.
- 표시 개수/조회 개수를 표시하고, 서버의 빈 목록과 검색 조건의 빈 결과를 구분한다. 초기화로 전체 목록을 다시 볼 수 있다.
- 조회 시 검색 문자열을 한 번 만들고 입력마다 카드 표시 여부만 바꾼다. 검색 때문에 추가 요청·다운로드·카드 재생성을 하지 않는다.
- 검색·종류·결과·스크롤은 Main의 세션 메모리에만 저장한다. 새로고침·창 재진입 때 유지하고 게임 종료 시 초기화한다.
- 첫 응답을 기다리는 빈 화면이 저장된 스크롤을 0으로 덮지 않도록 수신 완료 이후에만 위치를 갱신한다.
- 조건 변경 때는 맨 위로 이동하고 새로고침 때는 위치와 살아남은 코드의 버튼 초점을 유지한다. 화면 수명·복원 순번으로 지연 복원을 막는다.
- 숨겨진 카드 버튼은 Tab 순환에서 제외하고 남은 초점은 검색으로 옮긴다. 검색·필터·초기화 높이는 58이며 기존 고정 하단 버튼·키보드 스크롤·Esc·진입 버튼 초점 복귀를 유지한다.
- 조회 실패 시 기존 목록·조건을 유지한다. 기존 코드 복사·보기·로컬 보관·요청 중복 및 화면 수명 보호 흐름을 사용한다.
- README를 갱신하고 이전 1회차를 아카이브로 옮겨 최근 3회차만 남겼다. 응답 정규화·검색·카드 표시·초점·위치 복원 연결을 소스로 검토했다.
- 테스트는 추가·수정·실행하지 않았고 게임 실행·렌더링도 하지 않았다. 실제 로드·표시·조작 검증은 외부 스크립트에 맡긴다.
- 호환성 변경: 없음. RPC 시그니처·세이브·서버 파일 형식과 버전 번호·release.json·CHANGELOG·PatchNotes는 변경하지 않았다. Git 명령은 실행하지 않았다.
- 다음 후보: 도전 전투의 점수 근거를 리플레이 선택 창에서 확인하는 흐름, 사본 복구 전후 도전 기록의 날짜·버전별 상세 비교, 최근 온라인 전투 재생 후 검색 목록과 선택 카드로 바로 복귀하는 흐름.

## 2026-10-13 — 최근 온라인 전투의 보관 시각·정책 안내

- 이번 주제: 최근 온라인 전투에 서버 보관 시각·경과 시간·개수 기반 보관 정책을 표시하고 공유 코드 복사를 지원한다.
- 시작 상태: Git 명령 없이 인덱스·추적 파일 해시와 HEAD 트리를 비교했다. 미완료 변경은 없었으며 최근 3회차·아카이브의 다음 후보에서 미구현 주제를 선택했다.
- 확인한 문제: 목록에 날짜가 없고 코드 보관 기간이 안내되지 않아 전투를 찾거나 보존 여부를 판단하기 어려웠다.
- 서버의 기존 created_usec를 최근 목록 응답에 UTC 초 단위로 제공하고 보관 시각과 전투 시작·종료 시각을 구분한다.
- 이전 파일의 수정 시각은 추정으로 표시한다. 공개 전환·재시작 뒤에도 추정 여부를 유지해 확정 시각으로 오인하지 않는다.
- 경과 시간은 목록 조회 시점의 기기 시계 기준으로 계산하며 새로고침 때 갱신한다. 미래 시각에는 시계 확인을 안내한다.
- 시각의 숫자·범위·정수 여부와 양쪽 덱·결과·전투 시간을 응답 경계에서 확인한다. 시각 미제공·오류이면 미상으로 표시하고 정상 전투는 계속 재생한다.
- 공개 목록 최대 20개·서버 통합 최근 200개·고정 만료 시간 없음·새 업로드에 따른 오래된 코드 정리를 안내하고 보기 → 로컬 보관으로 보존하도록 안내한다.
- 각 카드에 전투 종류·결과·전투 시간을 표시하고 블루·레드 덱을 분리해 긴 병력 이름을 줄바꿈한다.
- 코드 복사 버튼은 추가 업로드 없이 클립보드로 코드를 복사한다. 복사 완료·클립보드 미지원 상태를 버튼에 표시한다.
- 코드 복사·보기·새로고침·닫기의 최소 높이는 58이다. 새로고침·닫기는 스크롤 밖의 하단 한 줄에 고정한다.
- 방향키·Page Up/Down·Home/End 스크롤, Tab 초점 순환, Esc 닫기와 진입 버튼 초점 복귀를 지원한다.
- 새로고침은 스크롤과 살아남은 코드의 버튼 초점을 유지한다. 화면 수명·복원 순번을 확인해 지연 복원을 막는다.
- 조회 실패 시 기존 목록을 유지한다. 정리되었거나 읽을 수 없는 코드에는 새로고침을 안내하며 기존 요청 수명 보호를 사용한다.
- README를 갱신하고 이전 1회차를 아카이브로 옮겨 최근 3회차만 남겼다. 시각 출처·저장·응답·화면 연결을 소스로 검토했다.
- 테스트는 추가·수정·실행하지 않았고 게임 실행·렌더링도 하지 않았다. 외부 스크립트가 검증한다. 버전 번호·release.json·CHANGELOG·PatchNotes는 변경하지 않았고 Git 명령도 실행하지 않았다.
- 호환성 변경: 최근 목록 응답에 stored_at·stored_at_estimated 선택 필드, 서버 공유 파일에 created_estimated 선택 필드 추가. 기존 파일·응답을 읽고 이전 리더는 추가 필드를 무시한다. RPC 시그니처·프로필 세이브·리플레이 형식은 유지한다.
- 다음 후보: 도전 전투의 점수 근거를 리플레이 선택 창에서 확인하는 흐름, 사본 복구 전후 도전 기록의 날짜·버전별 상세 비교, 최근 온라인 전투에서 날짜·덱·결과로 빠르게 찾는 흐름.

## 2026-10-13 — 진행도 복구 전후 캠페인·덱 상세 비교

- 시작 상태: Git 명령 없이 인덱스·추적 파일 해시와 HEAD·인덱스 루트 트리를 비교했다. 미완료 변경·새 소스·문서는 없었다.
- 최근 3회차와 아카이브의 다음 후보를 읽고, 남아 있던 사본 복구 전후 캠페인·덱 상세 비교를 선택했다.
- 확인한 문제: 사본과 현재 진행도의 총계만 보여 어떤 단계의 기록이 줄고 어떤 덱으로 바뀌는지 복구 전에 파악하기 어려웠다.
