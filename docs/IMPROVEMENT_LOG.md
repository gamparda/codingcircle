# 프로젝트 개선 기록

## 2026-10-14 — 오프라인 전투 일시정지와 앱 이탈 보호

- 이번 주제: 캠페인을 포함한 오프라인 전투에 버튼·Space 일시정지, 스탯 확인 중 정지, 앱 이탈 시 자동 정지와 명시적 재개를 제공한다.
- 시작 상태: Git 명령 없이 인덱스·추적 파일의 원본/LF 해시와 HEAD/인덱스 트리 해시를 직접 비교했다. 미커밋 변경·충돌·미추적 소스·문서가 없어 중단 작업은 없었다.
- 최근 기록·다음 후보와 아카이브 주제를 확인했다. 보관함 개선이 집중되어 있어 실제 플레이 중 자리를 비우거나 설명을 읽을 때의 전투 보호를 선택했고 소스 수정 전에 주제를 기록했다.
- 확인한 불편: 캠페인에는 일시정지가 없었고 스탯 창을 읽는 동안에도 전투가 계속됐다. 창 이탈·모바일 백그라운드 전환에도 전투가 진행될 수 있었다.
- 캠페인 전투 상단에 일시정지 버튼을 추가했다. 기존 연습·도전·드래프트·고스트·되감기 실험 버튼도 같은 일시정지 안내 창을 사용하며 Space로 조작한다.
- 안내 창은 계속하기 버튼과 Space/Enter로 재개한다. 버튼은 놓을 때 실행하고 높이 58을 적용하며 Tab 초점과 구매 키 입력이 뒤쪽 화면으로 넘어가지 않게 한다. F11 조작은 유지한다.
- 창의 앱 초점 이탈·모바일 앱 정지 알림에서 자동 정지한다. 돌아와도 직접 재개해야 하며 중복 알림은 같은 안내 창을 유지한다. 백그라운드에서 시작한 오프라인 전투도 정지한다.
- 오프라인 스탯·기존 확인창·요약 창이 열리면 로컬 시뮬레이션을 진행하지 않는다. 스탯 창에는 정지 안내와 닫기/Esc 조작을 제공하며 닫은 뒤 초점을 스탯 버튼으로 돌린다.
- 정지 중 전투 시간·자원 회복·모델의 생산 쿨다운과 AI 명령·전장 애니메이션을 멈춘다. 재개 첫 프레임의 경과 시간을 버려 백그라운드 체류 시간을 따라잡지 않는다.
- 기존 고정 30Hz 기록과 틱 잔여 시간은 유지한다. 정지 중 기록 틱을 추가하지 않고 배속·무한 자원·상대 덱 설정과 연습 도구 사용 판정은 바꾸지 않는다.
- 구매 카드·단축키·전장 설치는 같은 정지 상태를 확인한다. 선택한 구조물은 정지 사유만으로 해제하지 않으며 재개 후 기존 자원·설치 한도로 다시 판단한다.
- 진행 중인 터치 설치는 정지 시 중단한다. 앱 복귀 직후 손가락을 놓아 뜻하지 않은 설치가 일어나지 않으며 선택한 구조물로 새 동작을 시작할 수 있다.
- 앱 이탈 전 스탯·확인창과 키보드 초점을 유지한다. 자동 정지를 해제해도 원래 창이 열려 있으면 전투는 계속 정지하며 원래 창을 닫아야 진행된다.
- 화면 교체 시 정지 창을 숨기고 해제하며 이전 초점 참조를 비운다. 종료 결과·기지 붕괴 연출 중에는 새 정지를 만들지 않으며 온라인 대전·관전·서버 처리는 계속 진행한다.
- README를 갱신하고 가장 오래된 1회차를 아카이브로 옮겨 최근 3회차만 남겼다. 소스로 시작·정지·재개·화면 교체·구매 차단·기록 틱·연출과 모달 초점 경로를 검토했다.
- 테스트는 추가·수정·실행하지 않았고 게임 실행·렌더링도 하지 않았다. 실제 로드·창 전환·모바일 복귀·키보드·터치·리플레이 재현·기존 기능 검증은 외부 스크립트에 맡긴다.
- 호환성 변경: 없음. RPC 시그니처·세이브·서버 파일 형식과 버전 번호·release.json·CHANGELOG·PatchNotes를 유지했다. Git 명령은 실행하지 않았다.
- 다음 후보: 오프라인 스탯 창의 긴 설명을 좁은 화면에서 쉽게 탐색하는 흐름, 복구 비교에서 변경된 항목만 탐색하는 흐름, 보관함의 선택 검색어를 카드 밖에서도 개별 해제하는 조작.

## 2026-10-14 — 리플레이 보관함 읽기 분산과 화면 이탈 중단

- 이번 주제: 보관함의 파일 탐색·읽기를 짧은 배치로 나누고 진행 상황을 표시하며, 화면 이탈·새로고침 시 이전 읽기를 중단한다.
- 시작 상태: Git 명령 없이 인덱스·추적 파일의 원본/LF 해시와 압축 HEAD 객체의 트리를 직접 읽어 비교했다. 미커밋·충돌·미추적 소스·문서 변경은 없었다.
- 최근 기록과 아카이브의 다음 후보를 읽었다. 이번 주제와 배치 읽기 코드는 이미 커밋되어 있었지만 완료 기록이 빠져 있어 새 회차 대신 이를 마무리했다.
- 소스 수정 전에 재개 주제를 먼저 기록했다. 코드 창 즉시 복귀와 덱 분석의 전체 보관함 재사용을 함께 구현했다.
- 기존 배치 읽기는 화면에서 파일명을 최대 64개, 파일을 최대 4개씩 처리하며 배치 사이에 입력·화면 갱신을 허용한다.
- 배치 시작부터 약 4ms가 지나면 다음 항목을 다음 프레임으로 넘긴다. 개별 파일의 동기 읽기·JSON 파싱·검사와 완료 시 카드 생성 자체를 중간에 멈추는 제한은 아니다.
- 파일 탐색 중 발견 개수와 읽기 완료/전체 개수를 표시한다. 검색·용량·페이지·덱 분석은 전체 읽기가 끝난 뒤 준비해 부분 집계를 전체 결과로 표시하지 않는다.
- 읽는 동안 메인 화면·가져오기·코드·최근 온라인 전투 버튼을 사용할 수 있다. 화면 이탈·새로고침으로 이전 화면이 삭제 대기 상태가 되면 남은 읽기와 후속 동작을 중단한다.
- 폴더가 아직 없는 빈 보관함과 폴더 접근·목록 읽기 실패를 구분한다. 실패를 빈 용량으로 오인하지 않도록 안내하며 새로고침으로 재시도한다.
- 검색·양쪽 덱 조건·필터·정렬·페이지·파일별 카드 위치를 로딩 중 유지한다. 완료 후 기존 최대 8개 카드 생성과 초점·스크롤 복원을 사용한다.
- 삭제·보존 변경·정리 후 초점 복원은 읽기가 끝난 뒤 실행한다. 기다리는 동안 새 사용자 입력·다른 화면·확인창이 있으면 자동 이동을 우선하지 않는다.
- 확인한 추가 불편: 코드로 재생한 전투에서 나갈 때 코드 입력 창까지 전체 보관함 읽기를 기다려야 했고, 덱 분석은 완료한 파일 읽기를 다시 수행했다.
- 코드 재생 복귀는 이미 있는 진입 버튼을 사용해 입력 코드와 창을 즉시 복원한다. 보관함은 뒤에서 계속 읽으며 기존 확인창 초점 보호를 유지한다. 자동 접속·다운로드를 추가하지 않는다.
- 보관함의 덱 분석은 읽어 둔 전체 스냅샷을 사용해 파일 목록 탐색·JSON 재읽기를 없앴다. 검색으로 숨긴 기록과 다른 페이지의 정상 기록도 분석한다.
- 분석에는 최근 보관순으로 전달해 정렬 변경으로 대표 덱의 슬롯 순서가 바뀌지 않게 했다. 기존 승패·단계별 집계·팁과 독립 호출의 파일 기반 분석은 유지한다.
- 게임 밖에서 파일을 바꿨다면 분석 전에 새로고침하도록 도움말·README에 안내했다. 기존 분석의 서버 통계 조회는 유지한다.
- README를 갱신하고 가장 오래된 1회차를 아카이브로 옮겨 최근 3회차만 남겼다. 소스로 호출 경로·화면 수명·집계 범위·정렬·모달 초점과 기록 보관을 검토했다.
- 테스트는 추가·수정·실행하지 않았고 게임 실행·렌더링도 하지 않았다. 실제 로드·큰 보관함·키보드·터치·코드 복귀·덱 분석과 기존 기능 검증은 외부 스크립트에 맡긴다.
- 호환성 변경: 없음. RPC 시그니처·세이브·서버 파일 형식과 버전 번호·release.json·CHANGELOG·PatchNotes를 유지했다. Git 명령은 실행하지 않았다.
- 다음 후보: 복구 비교에서 변경된 항목만 빠르게 탐색하는 흐름, 보관함의 선택 검색어를 카드 밖에서도 개별 해제하는 조작, 보관함 읽기 뒤 현재 페이지 카드 생성 비용도 나누는 흐름.

## 2026-10-14 — 리플레이 보관함 카드에서 덱 검색 조작

- 이번 주제: 저장된 카드의 병력·구조물을 눌러 진영별 검색 조건을 추가·해제하고, 한쪽 또는 양쪽 전체 덱을 빠르게 찾는다.
- 시작 상태: Git 명령 없이 인덱스와 추적 파일의 원본/LF 해시, HEAD 루트 트리를 직접 비교했다. 미커밋 변경·충돌·미추적 소스·문서가 없어 중단 작업은 없었다.
- 최근 3회차와 아카이브의 다음 후보를 읽고 아직 남아 있던 보관함 카드의 덱 구성 검색 조작을 선택했다. 소스 수정 전에 주제를 한 줄 먼저 기록했다.
- 확인한 불편: 카드에 출전 구성은 보이지만 같은 병력·구조물이나 같은 대결을 찾으려면 상단 검색칸까지 이동해 이름을 직접 입력해야 했다.
- 정상 카드에 양쪽 병력·구조물 검색 버튼을 추가했다. 해당 진영 검색에 영문 ID를 추가하며 다른 검색어·반대 진영·필터·정렬은 유지한다.
- 선택 항목은 체크 표시와 눌린 모양으로 안내한다. 다시 누르면 해당 항목의 정확한 이름·ID 조건만 지우며 부분 검색어는 그대로 남긴다.
- 한쪽 전체 덱 검색과 양쪽 덱 전체 검색을 추가했다. 대상 검색칸을 저장된 전체 구성 ID로 교체해 같은 출전 구성·대결을 빠르게 찾는다.
- 전체 덱 버튼은 해당 칸의 모든 조건이 그 구성과 일치할 때만 검색 해제로 표시한다. 추가 수동 조건이 있으면 전체 덱 선택으로 오인해 지우지 않는다.
- 내 덱·상대 덱 표시는 캠페인·연습·일일/주간 도전·드래프트에 적용한다. 온라인·기타는 버튼과 도움말도 블루 덱·레드 덱 기준을 유지한다.
- 클립도 저장된 전체 전투의 출전 덱을 사용한다. 출전 순서·실제 생산/설치 수·현재 편성 덱으로 검색 대상을 바꾸지 않는다.
- 양쪽 검색칸을 함께 적용하고 목록을 한 번 갱신한다. 각 칸의 160자 한도를 먼저 검사해 초과 시 기존 조건·선택 표시를 유지하고 수정할 검색칸으로 초점을 옮긴다.
- 카드 조작은 파일 경로로 해당 카드가 있는 페이지를 찾고 스크롤·버튼 초점을 복원한다. 상단 검색칸으로 강제 이동하지 않아 여러 항목을 연속으로 고를 수 있다.
- 버튼에 진영·항목별 고정 이름을 지정했다. 새로고침·재생 복귀 시 기존 파일·컨트롤 식별과 화면 수명·복원 회차·사용자 입력 우선 처리를 사용한다.
- 직접 입력·초기화·페이지 이동·새로고침 뒤 선택 표시를 현재 조건으로 갱신한다. 재사용한 카드와 새로 만든 카드 모두 같은 조건을 따른다.
- 기존 도전 보관 전투의 검색어 토글·전체 덱 비교·버튼 스타일을 재사용했다. 진영 이름은 선택 메타데이터로 확장하고 기존 도전 선택 창의 동작은 유지한다.
