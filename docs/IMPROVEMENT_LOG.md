# 프로젝트 개선 기록

## 2026-10-13 — 코드 리플레이 재생 후 입력 창과 초점 복귀

- 이번 주제: 코드로 연 리플레이에서 나가면 입력 코드와 코드 창을 복원하고, 닫기·Esc 후 진입 버튼으로 키보드 초점을 돌린다.
- 시작 상태: Git 명령 없이 인덱스와 추적 파일 해시를 비교했다. 작업 트리의 추적 파일 변경과 미추적 소스·문서는 없었다. 기존 Python 바이트코드 캐시는 그대로 두었다.
- 최근 3회차와 아카이브의 다음 후보를 읽고 남아 있던 코드 재생 후 복귀를 선택했다. 소스 수정 전에 주제를 로그에 기록했다.
- 확인한 문제: 코드로 연 전투에서 나가면 보관함으로만 돌아가 코드 창과 입력 코드가 사라졌다. 코드 창을 닫아도 진입 버튼 초점이 복원되지 않았다.
- 코드 다운로드 성공 시 기존 공통 뷰어에 전용 복귀 콜백과 나가기 버튼 안내를 연결한다.
- 나가면 리플레이 보관함을 재구성한 뒤 코드 입력 창을 다시 연다. 보관함의 검색·필터·스크롤 상태는 기존 상태 사전을 사용한다.
- 입력 창에 성공적으로 열었던 대문자 코드를 복원하고 코드 입력에 초점을 둔다. 전체 선택해 다른 코드를 바로 입력할 수 있다.
- 복귀 상태에는 어떤 코드에서 돌아왔는지와 다시 열기·새 코드 입력 방법을 안내한다.
- 복귀만으로 서버 접속이나 다운로드를 요청하지 않는다. 다시 열기는 기존 요청 경로로 서버에서 다시 불러오며 연결 실패·정리된 코드 안내를 유지한다.
- 복귀 콜백은 Main과 코드 문자열만 보관한다. 이전 코드 창의 컨트롤이나 다운로드된 전투를 복귀용으로 붙잡지 않는다.
- 화면 배치 후 한 프레임에 창을 복원한다. 배경의 트리 수명·삭제 예약·현재 배경·다른 팝업 여부를 확인해 화면 전환 뒤 창이 다시 뜨지 않도록 한다.
- 닫기 버튼과 Esc는 같은 경로를 사용하며 해당 창이 소유한 다운로드를 즉시 해제한다. 서버 연결과 다른 채널의 요청은 유지한다.
- 닫기 뒤에는 원래 진입 컨트롤로 초점을 돌린다. 대상이 사라지거나 숨겨졌으면 현재 보관함의 코드로 열기 버튼을 사용한다.
- 초점 복원도 화면 수명과 현재 팝업을 확인한다. 다른 화면이나 새 팝업의 초점을 빼앗지 않도록 한다.
- 입력의 자동 대문자 변환 시 커서 위치를 유지해 코드 중간 글자를 수정할 수 있다.
- 기존 6자리 검증·중복 요청 잠금·취소·실패 재시도·Tab 순환·터치 최소 높이를 유지한다.
- 공통 뷰어의 로컬 보관·메모 저장 실패와 나가기 확인·되감기 실험 경로를 유지한다. 최근 전투·도전 전투의 기존 복귀 경로도 유지한다.
- README에 실제 조작과 다시 열기의 서버 조회를 안내했다. 이전 1회차를 아카이브로 옮겨 최근 3회차만 남겼다.
- 테스트는 추가·수정·실행하지 않았고 게임 실행·렌더링도 하지 않았다. 콜백 연결·입력 상태·화면 수명·기존 저장 경로를 소스로 검토했으며 실제 로드·조작 검증은 외부 스크립트에 맡긴다.
- 호환성 변경: 없음. RPC 시그니처·세이브·서버 파일 형식을 유지한다. 버전 번호·release.json·CHANGELOG·PatchNotes는 수정하지 않았고 Git 명령은 실행하지 않았다.
- 다음 후보: 진행도 복구 전 닉네임·새 기능 확인 상태의 변화 안내, 도전 보관 전투에서 내 덱·상대 덱을 나눠 검색하는 흐름, 코드 입력에 클립보드의 유효한 공유 코드를 붙여넣는 조작.

## 2026-10-13 — 도전 보관 전투의 덱 검색과 결과·클립 필터

- 이번 주제: 도전 보관 전투에서 양쪽 덱의 병력·구조물을 검색하고 결과·전체 전투/클립을 필터링하며 재생·새로고침 후 탐색 상태를 유지한다.
- 시작 상태: Git 명령 없이 인덱스·추적 파일 해시와 HEAD·인덱스 루트 트리를 비교했다. 미커밋 변경과 미추적 소스·문서는 없었다.
- 최근 3회차와 아카이브의 다음 후보를 읽고 남아 있던 도전 전투 덱 검색을 선택했다. 소스 수정 전에 주제를 로그에 기록했다.
- 확인한 문제: 덱 미리보기는 있지만 같은 날짜의 여러 전투에서 원하는 구성을 찾으려면 모든 카드를 읽어야 했다.
- 양쪽 저장 덱의 병력·구조물 한글 이름과 영문 ID를 검색한다. 대소문자를 구분하지 않고 공백으로 나눈 검색어를 모두 포함해야 한다.
- 파일명·보관 날짜·전투 시간·클립 제목·구간·길이와 버전 미상도 검색한다. 현재 덱이나 오늘의 도전 구성으로 대체하지 않는다.
- 승리·패배·무승부와 전체 전투만·클립만 필터를 추가했다. 결과는 내 덱(블루)의 전체 전투 기준이며 두 필터와 검색을 함께 적용한다.
- 검색 텍스트와 카드는 창 진입·새로고침 때 한 번 만든다. 입력마다 파일을 다시 읽거나 카드를 재생성하거나 전투를 시뮬레이션하지 않는다.
- 전체·그룹별 표시 개수를 안내하고 후보가 없는 그룹 제목을 숨긴다. 검색 결과 없음과 보관 전투 자체가 없음을 구분하며 초기화로 전체 후보를 복원한다.
- 버전 확인·미상 그룹과 각 그룹의 최신 보관순을 유지한다. 검색은 이 날짜·종류·버전의 기존 후보 안에서만 수행한다.
- 검색·결과·클립 조건을 재생 후 복귀와 새로고침에 보존한다. 기존 완료 분석·스크롤·선택 카드 초점과 기록 화면 복귀도 유지한다.
- Tab 순환은 보이는 사용 가능한 조작만 포함하며 숨겨지거나 잠긴 버튼의 초점을 검색으로 돌린다. Esc 닫기와 키보드 스크롤을 유지한다.
- 검색으로 분석 중인 카드가 숨겨지면 그 분석만 취소한다. 이미 완료된 분석은 유지하고 다시 표시할 때 재사용한다.
- 화면 수명과 복원 순번을 확인해 빠른 연속 검색이나 창 종료 뒤 이전 스크롤 복원이 적용되지 않도록 했다.
- 검색·필터·초기화에 터치 최소 높이 58을 적용했다. 창을 넓히고 긴 설명을 목록 스크롤로 옮겨 카드 공간을 확보했다.
- 재생·분석 직전 파일 재확인과 지문 비교, 기록·파일·순위표의 읽기 전용 흐름은 유지한다. README를 갱신하고 이전 1회차를 아카이브로 옮겨 최근 3회차만 남겼다.
- 테스트는 추가·수정·실행하지 않았고 게임 실행·렌더링도 하지 않았다. 소스의 데이터 흐름·화면 수명·초점 연결을 검토했으며 실제 로드·표시·조작 검증은 외부 스크립트에 맡긴다.
- 호환성 변경: 없음. RPC 시그니처·세이브·서버 파일 형식을 유지한다. 버전 번호·release.json·CHANGELOG·PatchNotes는 수정하지 않았고 Git 명령은 실행하지 않았다.
- 다음 후보: 코드로 연 전투 재생 후 입력 코드와 진입 버튼 초점 복원, 진행도 복구 전 닉네임·새 기능 확인 상태의 변화 안내, 도전 보관 전투에서 내 덱·상대 덱을 나눠 검색하는 흐름.

## 2026-10-13 — 진행도 복구 전 시작 목표·튜토리얼 상태 비교

- 이번 주제: 사본 선택·가져오기·최종 복구 확인에서 시작 목표별 완료 변화와 튜토리얼 완료 상태를 비교해 다시 해야 할 항목을 미리 안내한다.
- 시작 상태: Git 명령 없이 인덱스·추적 파일 해시와 HEAD·인덱스 루트 트리를 비교했다. 미커밋 변경과 미추적 소스·문서는 없었다.
- 최근 3회차와 아카이브의 다음 후보를 읽고 남아 있던 시작 목표·튜토리얼 복구 비교를 선택했다. 소스 수정 전에 주제를 로그에 기록했다.
- 확인한 문제: 사본으로 복구하면 목표·튜토리얼 완료 기록도 바뀌지만, 기존 비교에는 이 변화가 표시되지 않았다.
- 시작 목표별 현재·사본 완료 여부를 비교하고 다시 미완료로 바뀌는 목표의 이름·안내를 먼저 표시한다.
- 완료 총수가 같거나 늘어도 기존 완료 목표의 상실을 따로 경고한다. 다른 목표의 증가로 상쇄하지 않는다.
- 새로 완료되는 목표는 손실 목록 뒤에 표시하며, 상태 유지 개수와 변경 없음도 안내한다.
- 실제 메뉴의 Goals.is_done을 재사용한다. 첫 승리·일일 도전·온라인 대전은 누적 전적으로 판정한다.
- 내 덱 만들기·드래프트·리플레이 보기는 저장된 목표 완료 기록으로 판정한다. 오늘의 도전 기록·업적 개수로 추정하지 않는다.
- 목표 제목·안내·전체 개수와 다음 추천은 기존 Goals 정의·함수를 사용한다. 목표 판정 규칙과 완료 기록을 바꾸지 않는다.
- 현재 → 사본의 다음 추천을 표시한다. 모든 목표 완료 여부가 바뀌면 메인 메뉴 시작 목표 버튼의 표시·숨김 변화도 설명한다.
- 튜토리얼 완료 상태를 별도로 비교한다. 완료가 안내 수행 또는 건너뛰기를 뜻하며 승리 여부와 별개임을 안내한다.
- 완료 → 미완료이면 다음 캠페인·AI 연습에서 소환·설치·자원 회복 안내가 다시 표시되고 건너뛸 수 있음을 경고한다.
- 미완료 → 완료이면 첫 전투 안내를 자동 표시하지 않는다고 설명한다. 같은 상태에는 변경 없음을 표시한다.
- 공통 비교에 연결해 사본 선택·클립보드 가져오기·최종 복구 확인 세 화면에서 동일하게 표시한다.
- 손실은 경고색과 글자로 구분하고 기존 세로 스크롤·줄바꿈을 사용한다. 새 조작 버튼이나 초점 정지점은 추가하지 않는다.
