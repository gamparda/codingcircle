# 프로젝트 개선 기록

## 2026-10-14 — 전장 병력 직접 선택과 전투 상태 확인

- 이번 주제: 움직이는 병력을 클릭·터치해 현재 체력·분노·저주·공속 지원 상태를 전투를 멈추지 않고 확인한다.
- 시작 상태: Git 명령 없이 인덱스와 작업 파일의 원본/LF 해시, 재구성한 인덱스 트리와 HEAD 트리를 대조했다. 미커밋·스테이징 변경·충돌·미추적 파일이 없어 중단 작업은 없었다.
- 최근 3회차·아카이브 주제·다음 후보를 읽고 실제 전투에서 자주 마주치는 개별 병력 상태 확인을 선택했다. 소스 수정 전에 주제를 먼저 기록했다.
- 확인한 불편: 전장은 작은 체력 막대·광폭/저주 표식만 표시하고, 병력 현황은 종류별 인원·일반 스탯을 보여 주어 개별 병력의 현재 수치를 읽기 어려웠다.
- UnitInspection에 병력 좌표·클릭 판정·읽기 전용 카드 그리기를 모으고, 기존 StructureInspection의 입력 소유권·취소·화면 수명 경로를 함께 사용한다.
- 건설 선택이 없을 때 양쪽 병력 본체·체력 막대를 클릭·터치해 선택한다. 겹치면 가까운 본체, 같은 거리면 앞에 그려진 병력을 고르고 구조물보다 병력을 우선한다.
- 병력과 구조물의 ID 공간을 구분해 숫자 ID가 같아도 혼동하지 않는다. 누름 뒤 다른 병력이 더 가까워져도 놓는 위치가 원래 병력 영역 안이면 원래 ID를 선택한다.
- 금색 테두리·발밑 표식·연결선과 전장 위쪽 상태 카드로 선택 대상을 표시한다. 위치는 기존 화면 반전·온라인 위치 보간을 따라가며 전투 수치는 보간하지 않는다.
- 현재/최대 체력·비율·막대와 현재 공격력·공속 배율을 표시한다. 체력 25% 이하는 사망 주의를 색상과 문구로 함께 강조한다.
- 공격력은 실제 병력의 성장 반영 damage와 현재 위치의 저주 감소율을 사용한다. 공속은 지원 중첩과 분노 배율을 곱해 전투 판정과 같은 기준으로 표시한다.
- 지원 중첩은 0~최대 범위로 표시하고, 마법사는 직접 공격하지 않는 공속 지원 병력이며 지원 효과를 받지 않는다고 안내한다.
- 저주는 상대 진영·현재 위치·만료 전투 시각으로 판정한다. 중첩 장판의 감소율은 한 번만 적용하고 모든 유효 장판이 만료되기까지의 시간과 벗어나면 해제됨을 안내한다.
- 광전사는 분노 발동 여부·공속 배율 또는 발동 체력 기준을 표시한다. 네크로맨서는 받은 summon_remaining으로 다음 해골 소환 시간을 표시하고 누락 시 정보 없음으로 안내한다.
- 소환된 해골도 선택할 수 있으며 소환 병력이라고 표시한다. 관전은 블루·레드 이름을 사용하며 최신 스냅샷으로 같은 병력의 상태를 갱신한다.
- 실제 시간으로 타이머를 줄이지 않아 배속·수신 지연에도 전투 시간 기준을 유지한다. 병력 사망·제거·전투 시각 되돌림에는 이전 선택을 버린다.
- 같은 병력 재선택·빈 전장·Esc로 닫고 병력/구조물 사이에 바로 전환한다. 드래그·전장 밖 해제·OS 취소·다른 손가락/버튼·키 입력의 선택 취소를 유지한다.
- 건설 선택·설치 응답 대기·일시정지·모달·채팅·최신 상태 대기·연결 복구·앱 이탈·종료의 정리를 공유한다. 에뮬레이션 해제 소비와 기존 생산·설치·리플레이 조작을 유지한다.
- 병력 현황 툴팁·README에 직접 확인 방법과 상태·시간 기준을 추가했다. 소스로 모델 판정·보간·ID·입력 해제·화면 수명·관전 경로를 검토했다.
- 테스트 추가·수정·실행과 게임 실행·로드 검사·렌더링은 하지 않았다. 실제 로드·움직이는/겹친 병력·상태 효과·터치/마우스·배속·관전·재접속·화면 배치는 외부 스크립트에 맡긴다.
- 호환성 변경: 없음. RPC 시그니처·세이브·서버 파일 형식과 버전 번호·release.json·CHANGELOG·PatchNotes를 유지했다. Git 명령은 실행하지 않았다. 가장 오래된 회차를 아카이브로 옮겨 최근 3회차만 남겼다.
- 다음 후보: 밀집한 병력에서 겹친 후보를 순환 선택하는 조작, 복구 비교의 특정 감소 경고에서 상세로 바로 이동하는 흐름, 도전 보관 전투 검색 결과의 페이지 번호 직접 이동.

## 2026-10-14 — 전장 구조물 직접 선택과 실시간 상태 확인

- 이번 주제: 전장 구조물을 클릭·터치해 종류·진영·체력·수명·발전기 수입을 바로 확인하고, 건설·드래그·화면 중단 입력과 충돌하지 않게 한다.
- 시작 상태: Git 명령 없이 인덱스와 작업 파일의 원본/LF 해시를 비교하고 loose·pack 객체에서 HEAD 트리와 인덱스 트리를 대조했다. 미커밋·스테이징 변경·충돌·미추적 파일이 없어 중단 작업은 없었다.
- 최근 3회차와 아카이브의 주제·다음 후보를 읽고, 보관함·복구 비교보다 전투 중 자주 쓰는 구조물 직접 확인을 선택했다. 소스 수정 전에 이번 주제를 기록했다.
- 확인한 불편: 구조물은 전장에 개별 체력을 표시하지 않으며, 종류·체력·수명을 함께 보려면 전체 현황 창에서 위치를 찾아야 했다. 오프라인은 현황 창을 읽는 동안 전투도 멈췄다.
- StructureInspection에 읽기 전용 선택·포인터 소유권·상태 카드 그리기를 모았다. Main은 입력 종료 포착·상태 동기화·앱 이탈 정리를 연결한다.
- 건설 카드를 선택하지 않았을 때 구조물 본체를 클릭·터치해 선택한다. 방벽·포탑·발전기와 낮고 넓은 늪의 모양에 맞춰 영역을 잡고 겹치면 가까운 본체를 고른다.
- 선택한 구조물에 금색 테두리를 두르고 연결선으로 전장 위쪽의 상태 카드를 가리킨다. 전열·피해 숫자·하단 늪 수명·구매 카드 영역을 피했다.
- 종류·아군/적군·현재/최대 체력·체력 비율·체력 막대를 표시한다. 체력 25% 이하는 색상과 파괴 주의 문구로 함께 강조한다.
- 관전에서도 양쪽 구조물을 확인할 수 있으며 진영 이름은 블루·레드로 표시한다. 화면 반전은 기존 world_to_screen_x·display_side를 따른다.
- 늪은 남은 수명·소수 첫째 자리까지의 만료 전투 시각을 표시하며 2초 이하는 금색·임박 문구로 강조한다. 수명 정보가 없으면 추정하지 않는다.
- 발전기는 전투 초당 추가 수입·수명 제한 없음을 표시한다. 방벽·포탑은 파괴될 때까지 유지된다고 안내한다.
- 전투를 멈추거나 추가 통신하지 않고 마지막 스냅샷으로 갱신한다. 실제 시간으로 수명을 줄이지 않아 연습 배속·온라인 수신 지연에도 기존 시간 기준을 유지한다.
- 구조물 ID로 선택을 유지하며 매번 최신 스냅샷에서 찾는다. 파괴·만료·제거된 구조물은 닫고, 전투 시간이 되돌아가면 이전 선택을 버린다.
- 같은 구조물 재선택·빈 전장 클릭/터치·Esc로 닫는다. 다른 구조물을 누르면 바로 전환하며, Esc는 기존 병력 반복 생산 취소도 유지한다.
- 누른 곳과 놓은 곳이 같은 구조물이어야 선택한다. 14 논리 픽셀 이상 이동·전장 밖 이동/놓기·OS 취소·추가 손가락/버튼·키 입력은 해당 선택 동작을 취소한다.
- 선택 동작을 전장 GUI에서 시작하고, 종료·드래그는 Main 입력에서 먼저 받는다. 카드나 모달 위에서 손을 떼도 아래 버튼의 구매·설치로 이어지지 않는다.
- 터치에서 생성된 에뮬레이션 마우스 누름·해제도 소비한다. 새 실제 터치·앱 이탈은 남은 에뮬레이션 기록을 정리해 이후 HUD 조작을 막지 않는다.
- 건설 선택·설치 응답 대기·일시정지·스탯/요약/확인창·채팅·상태 수신 대기·연결 복구·앱 이탈·종료에서는 정보를 닫는다. 기존 건설·생산·리플레이 병력 선택/확대/이동은 유지한다.
- 현황 버튼의 안내·툴팁과 README에 직접 확인 조작을 추가했다. 소스로 좌표 변환·포인터 해제·에뮬레이션·모달·관전·반전·스냅샷·화면 수명 경로를 검토했다.
- 테스트 추가·수정·실행과 게임 실행·로드 검사·렌더링은 하지 않았다. 실제 로드·터치/마우스·멀티터치·드래그·중첩 구조물·배속·관전·재접속·화면 배치는 외부 스크립트에 맡긴다.
- 호환성 변경: 없음. RPC 시그니처·세이브·서버 파일 형식과 버전 번호·release.json·CHANGELOG·PatchNotes는 유지했다. Git 명령은 실행하지 않았으며 가장 오래된 회차를 아카이브로 옮겨 최근 3회차만 남겼다.
- 다음 후보: 전장 병력을 직접 선택해 현재 체력·분노·저주 상태를 확인하는 흐름, 복구 비교에서 특정 감소 경고의 상세로 바로 이동하는 흐름, 도전 보관 전투 검색 결과의 페이지 번호 직접 이동.

## 2026-10-14 — 전장 구조물의 만료 예고와 재설치 대기 안내

- 이번 주제: 늪의 남은 수명·만료 임박을 전장에 표시하고, 구조물 한도 때문에 기다리는 카드에 가장 빠른 만료 시점을 안내한다.
- 시작 상태: Git 명령 없이 인덱스와 작업 파일의 원본/LF 해시를 대조하고 loose·pack 객체에서 HEAD 트리와 인덱스 트리를 비교했다. 미커밋·스테이징 변경·충돌·미추적 파일이 없어 중단 작업은 없었다.
- 최근 3회차와 아카이브의 주제·다음 후보를 읽고, 반복 생산·키보드 배치와 겹치지 않는 구조물 만료 안내를 선택했다. 소스 수정 전에 이번 주제를 로그에 적었다.
- 확인한 불편: 늪의 전장 수명 표시는 11px 숫자·얇은 막대여서 읽기 어려웠고, 설치 한도에 막힌 카드는 만료로 빈자리가 생길 시점을 알려주지 않았다.
- StructureLifetime에 읽기 전용 수명·전투 시각·만료 정렬·한도 해제 예상 계산을 모았다. 기존 expires_at·elapsed와 현재 구조물 수만 사용한다.
- 전장과 공통 리플레이 뷰에서 늪 수명을 14px 숫자·진영 테두리·어두운 배경·수명 막대로 표시한다. 시각 효과나 피해 숫자를 꺼도 남은 수명을 확인할 수 있다.
- 남은 2초 이하는 금색과 !로 강조한다. 가까운 늪의 표시는 가로 위치에 따라 행을 나눠 겹침을 피하고, 연결선으로 해당 구조물을 가리킨다.
- 수명 표시는 저주 타이머 아래와 하단 현황 버튼 위에 배치한다. 키보드 설치 안내·설치 불가 사유는 전장 위쪽의 어두운 배경에 옮겨 수명 표시와 겹치지 않게 했다.
- 구조물 현황 버튼의 두 번째 줄에 가장 빠른 아군 늪의 만료 시간과 2초 이하인 늪 개수를 표시한다. 관전은 현재 표시 진영을 기준으로 안내한다.
- 최신 전투 상태를 기다리거나 재접속·복구 대기 중에는 버튼에 수명 정보 수신 대기를 표시한다. 만료 구조물이 아직 수신 상태에 남아 있으면 상태 확인 중으로 안내한다.
- 상세 창은 체력·파괴 주의와 수명 안내를 별도 줄로 표시한다. 늪에는 남은 수명·소수 첫째 자리까지의 만료 전투 시각·만료 임박을 표시한다.
- 방벽·포탑·발전기는 수명 제한 없음·파괴될 때까지 유지를 표시한다. 수명 정보가 없는 늪은 정보 없음으로 표시하고 만료 시각을 추정하지 않는다.
- 한도에 막힌 구매 카드에 한도 · 만료 N초를 표시한다. 설치 순서가 아닌 만료 순서대로 전체·종류별 한도를 함께 살펴 두 한도가 모두 풀릴 때만 안내한다.
- 예를 들어 포탑이 이미 설치된 상태에서 늪이 만료되어도 포탑 종류 한도는 유지되므로 포탑 카드에는 만료 대기를 표시하지 않는다. 영구 구조물의 파괴 시점도 추정하지 않는다.
