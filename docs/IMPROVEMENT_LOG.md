## 2026-10-13 — 리플레이 시점별 전투 요약과 병력 기여도 비교

- 이번 주제: 리플레이의 원하는 시점과 종료 화면에서 누적 전투 집계·병력별 기여도를 확인하고, 요약을 닫으면 이전 재생 상태로 복귀한다.
- 시작 상태: Git 명령 없이 인덱스와 추적 파일 내용 해시, 압축된 HEAD 객체와 인덱스 루트 트리를 읽어 비교했다. 미완료 변경이나 새 소스·문서 파일은 없었다.
- 최근 3회차와 아카이브의 다음 후보를 확인하고, 남아 있던 리플레이의 전투 집계 조회를 선택했다.
- 확인한 문제: 리플레이는 승패 배너만 표시하며, 결과 화면에서 제공하는 병력별 기여도를 다시 확인할 수 없었다.
- 재생 화면에 전투 요약 버튼과 R 단축키를 추가했다. 원하는 장면으로 탐색한 뒤 그 시점까지의 누적 집계를 열 수 있다.
- 기존 승패 종료 배너에도 전투 요약 버튼을 추가해 끝난 전투의 전체 성과를 확인할 수 있다.
- 양 진영의 사용 자원·건설·처치·실제 피해와 병력별 피해/처치 전환·비중·공통 눈금 막대를 표시한다.
- 생산·포탑 건설·해골 소환 수, 공격 기록이 없는 지원 병력, 빈 집계·1 미만 피해 표시를 유지한다.
- 요약 제목에 실제 재생 시각을 표시한다. 클립에서도 전투 시작부터의 누적 집계이며, 현재 규칙으로 재현한 수치임을 안내한다.
- 요약은 현재 재생 모델의 집계 사본을 사용한다. 항목 전환은 고정된 사본만 읽으며 이후 재생·새 전투의 데이터에 접근하지 않는다.
- 요약을 열면 재생을 멈추고 병력 상세 창을 닫는다. 배경 클릭과 리플레이 탐색·재생 단축키가 요약 뒤의 전투에 개입하지 않도록 했다.
- 닫기 또는 Esc는 열기 전 일시정지 여부와 키보드 초점을 복원한다. 이미 멈춘 클립·수동 일시정지는 닫아도 재생하지 않는다.
- 직접 탐색·재시작 경로는 기존 요약을 즉시 분리한다. 본문 스크롤·고정 닫기·터치 최소 높이·내부 초점 순환과 방향키·Page Up/Down·Home/End 탐색을 지원한다.
- 기존 비교 UI를 공통 BattleReportContent로 옮겨 결과와 리플레이가 동일한 표시를 사용한다. 결과의 전세 그래프·진영 이름·닫기 흐름은 유지한다.
- 요약을 열 때 추가 전투 재계산이나 디스크 저장을 수행하지 않는다. 기존 메모·반복 구간·분기 실험·보관 흐름은 유지한다.
- README를 갱신하고 이전 1회차를 아카이브로 옮겨 최근 3회차만 남겼다.
- 검토: 재생 모델 집계, 공통 UI 연결, 종료·클립·일시정지·탐색 분기, 모달 입력·초점·화면 수명을 소스로 검토했다.
- 테스트는 추가·수정·실행하지 않았고 게임 실행·렌더링도 수행하지 않았다. 실행 검증은 외부 스크립트에 맡긴다.
- 호환성 변경: 없음. RPC 시그니처·세이브·서버 파일 형식·전투 수치·버전 번호·release.json·CHANGELOG·PatchNotes는 변경하지 않았다. Git 명령은 실행하지 않았다.
- 다음 후보: 도전 기록의 실제 달력 날짜·완료 시간 로드 검증, 진행도 사본의 내보내기·관리 흐름, 리플레이 병력 기여도의 선택 구간 비교.

## 2026-10-12 — 전투 요약의 병력별 기여도 비교

- 이번 주제: 양 진영의 병력별 실제 피해·처치 비중을 같은 눈금으로 비교하고, 생산·소환 수와 지원 병력의 집계 범위를 함께 안내한다.
- 시작 상태: Git 명령 없이 인덱스·추적 파일 내용 해시와 HEAD·인덱스 루트 트리를 읽어 비교했다. 미완료 변경이나 새 파일은 없었다.
- 최근 3회차와 아카이브의 다음 후보를 읽고, 아직 구현되지 않은 병력별 피해·처치 비중 비교를 선택했다.
- 확인한 문제: 양 진영이 서로 다른 병력 목록을 표시해 같은 병력의 성과를 비교하기 어려웠고, 네크로맨서의 해골 소환 수도 화면에 빠져 있었다.
- 전투 요약에 실제 피해·처치 전환 버튼과 병력별 비교 카드를 추가했다. 버튼은 키보드 초점과 터치 최소 높이를 지원한다.
- 양 진영에서 사용한 병력을 합쳐 같은 행에 표시하고, 선택한 항목의 양 진영 합계가 큰 순서로 정렬한다.
- 동점에서는 기존 병력 순서를 유지해 항목 순서가 불필요하게 흔들리지 않도록 했다.
- 각 진영의 수치·전체 대비 비중과 공통 눈금의 막대를 함께 표시한다. 막대 길이와 진영별 비중의 의미를 구분해 안내한다.
- 색상과 함께 파랑·빨강 문구를 표시하고, 상단에는 기존 플레이어 이름·사용 자원·건설·처치·피해 합계를 유지한다.
- 생산 수·포탑 건설 수를 구분하고, 네크로맨서에는 해골 소환 수도 표시한다.
- 생산·소환 기록이 있는 지원 병력은 피해·처치가 없어도 목록에 유지한다. 양쪽 모두 사용하지 않은 병력만 제외한다.
- 선택한 집계가 모두 0이면 기록이 없음을 안내하고 비중을 0%로 표시한다. 생산·소환·공격 기록도 없으면 빈 목록 안내를 표시한다.
- 0보다 크고 1보다 작은 피해는 ‘1 미만’으로 표시한다. 정렬·막대·비중 계산에는 반올림 전 실제 수치를 사용한다.
- 피해에는 병력·구조물·기지의 실제 체력 감소가 포함되고, 처치는 병력에 한정됨을 설명한다. 해골 합산과 치유·방어·자원 효과 제외도 안내한다.
- 비교 버튼은 확정 집계 사본을 사용하며 원본을 수정하지 않는다. 막대는 정적 컨트롤로 표시해 매 프레임 갱신을 추가하지 않았다.
- 기존 전세 그래프·스크롤·고정 닫기·전투 입력 차단 흐름을 유지하고 README를 갱신했다. 이전 1회차는 아카이브로 옮겨 최근 3회차만 남겼다.
- 검토: 집계 발생 지점, 최종 스냅샷 검증, 병력 합치기·정렬·0 집계 분기와 결과 화면 수명을 소스로 검토했다.
- 테스트는 추가·수정·실행하지 않았고 게임 실행·렌더링도 수행하지 않았다. 실행 검증은 외부 스크립트에 맡긴다.

- 다음 후보: 도전 기록의 실제 달력 날짜·완료 시간 로드 검증, 진행도 사본의 내보내기·관리 흐름, 리플레이 종료 화면에서 병력별 집계 확인.
