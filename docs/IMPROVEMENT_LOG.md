## 2026-10-14 — 진행도 복구 비교의 변경 항목 필터와 바로가기

- 이번 주제: 복구 비교에서 변경된 항목만 표시하고 항목별 바로가기로 상세를 펼쳐 이동하며, 기존 손실 경고와 비교 상태를 유지한다.
- 시작 상태: Git 명령 없이 인덱스·추적 파일의 원본/LF 해시와 HEAD/인덱스 트리 해시를 직접 비교했다. 미커밋 변경·충돌·미추적 소스·문서가 없어 중단 작업은 없었다.
- 최근 3회차와 아카이브의 다음 후보를 읽고 아직 남아 있던 복구 비교 탐색을 선택했다. 소스 수정 전에 이번 주제를 한 줄 먼저 기록했다.
- 확인한 불편: 변화가 없는 닉네임·튜토리얼 등도 아홉 항목의 요약을 차지했고, 아래쪽 덱·도전 변경을 보려면 긴 비교를 스크롤해야 했다.
- 변경된 항목만 체크를 추가했다. 기본은 기존 전체 표시이며, 변경 없는 항목의 요약·상세를 함께 숨긴다.
- 비교 항목별 변경·동일 표시와 전체 개수를 제공한다. 안내 범위 밖의 과거 기능 ID까지 동일하다는 뜻이 아님을 함께 설명한다.
- 변경 항목별 바로가기를 추가했다. 해당 상세만 펼치고 항목 버튼에 초점을 옮겨 스크롤하며 다른 항목의 접기 상태는 유지한다.
- 전적·업적·목표·튜토리얼·닉네임·새 기능·도전은 기존 정규화된 상세 비교 결과를 재사용한다. 총 개수가 같아도 개별 기록의 변화가 있으면 변경이다.
- 캠페인은 단계별 기록 외에 개방 단계·총 별·성장 단계 변화도 포함한다. 단계 기록이 같아도 개방만 바뀐 항목을 숨기지 않는다.
- 덱은 이름·병력·구조물·순서 외에 최근 선택 슬롯만 달라진 경우도 변경이다. 필터와 바로가기는 실제 복구 범위를 바꾸지 않는다.
- 기존 상단 요약·손실 경고와 전체 복구 안내는 필터 밖에 남긴다. 아홉 항목 모두 동일하면 빈 결과 안내와 조건 해제 방법을 표시한다.
- 모두 펼치기·모두 접기는 표시 중인 항목에만 적용한다. 숨긴 항목의 접기 상태와 덱 슬롯·도전 검색·필터·페이지를 유지한다.
- 사본 변경·새로고침·보관·가져오기·복구 확인에서 필터를 화면 상태로 유지한다. 저장 파일에 탐색 상태를 추가하지 않는다.
- 필터로 숨긴 항목에 이전 초점이 있으면 변경 항목만 체크로 복원한다. 접힌 상세의 항목 버튼 복귀와 사본 부재 시 목록 복귀도 유지한다.
- 새 조작은 놓을 때 실행하며 터치 높이·줄바꿈을 적용한다. 확인창의 기존 Tab·방향키 연결은 필터와 바로가기 조작 후 현재 보이는 활성 조작으로 갱신한다.
- README를 갱신하고 가장 오래된 1회차를 아카이브로 옮겨 최근 3회차만 남겼다. 소스로 비교 판정·공유 상태·초점 복원·모달 탐색·숨긴 항목의 접기 경로를 검토했다.
- 테스트는 추가·수정·실행하지 않았고 게임 실행·렌더링도 하지 않았다. 실제 로드·필터·바로가기 스크롤·터치·확인창 키보드·새로고침 복귀 검증은 외부 스크립트에 맡긴다.
- 호환성 변경: 없음. RPC 시그니처·세이브·서버 파일 형식과 버전 번호·release.json·CHANGELOG·PatchNotes를 유지했다. Git 명령은 실행하지 않았다.
- 다음 후보: 보관함의 선택 검색어를 카드 밖에서도 개별 해제하는 조작, 스탯 창의 검색·진영 선택을 같은 전투에서 다시 열 때 유지하는 흐름, 복구 비교에서 특정 감소 경고의 상세로 바로 이동하는 흐름.

## 2026-10-14 — 전투 스탯의 양쪽 출전 덱·성장 수치 비교

- 이번 주제: 스탯 창에서 내 덱·상대 덱·공통/전용 구성을 선택하고 진영별 성장 수치를 비교하며, 온라인은 이미 받은 출전 정보만 사용한다.
- 시작 상태: Git 명령 없이 인덱스·추적 파일의 원본/LF 해시와 HEAD/인덱스 트리 해시를 직접 비교했다. 미커밋 변경·충돌·미추적 소스·문서가 없어 중단 작업은 없었다.
- 최근 3회차·다음 후보와 아카이브 주제를 읽고 양쪽 출전 덱 비교를 선택했다. 소스 수정 전에 이번 주제를 한 줄 먼저 기록했다.
- 확인한 불편: 상대 덱의 병력·구조물만 고르거나 공통·전용 구성을 구분할 수 없었고, 성장 수치는 내 진영 기준으로만 표시됐다.
- 진영 선택에 내 진영·상대 진영·양쪽 비교·공통 출전·내 전용 출전·상대 전용 출전을 추가했다. 관전에서는 블루·레드 기준으로 표시한다.
- 기존 출전 덱만 체크를 내·상대·양쪽에 맞춰 적용한다. 공통·전용 선택은 출전 구성으로 한정하며 기존 체크 상태와 검색어는 유지한다.
- 카드 제목에 양쪽·내·상대 출전 여부를 표시한다. 네크로맨서의 해골은 소환으로 구분하고 양쪽 구성 필터에 포함한다.
- 검색과 무관한 공통·전용 구성 개수를 분류별로 표시한다. 병력 개수에는 소환 병력도 포함한다고 안내해 덱 슬롯 수로 오인하지 않게 한다.
- 오프라인 양쪽 덱·성장 단계는 실제 모델에서 읽는다. 캠페인·도전·드래프트·고스트·되감기 실험의 구성을 따로 추정하지 않는다.
- 양쪽 병력 수치가 같으면 하나로 표시하고 다르면 같은 카드에서 진영별로 보여 준다. 미출전 진영의 값은 참고용으로 명시한다.
- 기존 병력 설명 생성 함수·성장 보너스 함수를 재사용한다. 일시적인 지원·장판 효과를 제외한 기준 수치임을 안내하며 밸런스는 바꾸지 않는다.
- 전투 규칙에 오프라인 양쪽 진영의 실제 기지 최대 체력·자원 회복·한도·병력 성장률을 각각 표시한다.
- 온라인 방 상태의 플레이어 순서는 서버 진영 배정 순서와 대조했고, 플레이어는 자기 ID·진영이 맞는 진행 중/종료된 방 정보만 사용한다.
- 상대 덱 정보가 없는 연결에서는 비교 선택을 비활성화하고 이유를 안내한다. 관전의 미확인 덱을 개인 저장 덱으로 대체하지 않으며, 기존 방 연결의 내 덱은 제출한 클라이언트 덱을 사용한다.
- 진영 선택 메뉴에 터치 간격과 Tab 초점을 제공한다. Esc는 열린 선택 메뉴부터 닫고 다음 입력으로 스탯 창을 닫는다. 자동 정지 때 선택 메뉴를 닫아 정지 안내를 가리지 않게 한다.
- README를 갱신하고 오래된 1회차를 아카이브로 옮겨 최근 3회차만 남겼다. 소스로 진영 배정·정보 부재·필터 조합·성장 산식·팝업과 모달 입력 우선순위를 검토했다.
- 테스트는 추가·수정·실행하지 않았고 게임 실행·렌더링도 하지 않았다. 실제 로드·진영별 필터·관전·기존 방 연결·팝업·자동 정지 복귀 검증은 외부 스크립트에 맡긴다.
- 호환성 변경: 없음. RPC 시그니처·세이브·서버 파일 형식과 버전 번호·release.json·CHANGELOG·PatchNotes를 유지했다. Git 명령은 실행하지 않았다.
- 다음 후보: 복구 비교에서 변경된 항목만 탐색하는 흐름, 보관함의 선택 검색어를 카드 밖에서도 개별 해제하는 조작, 스탯 창의 검색·진영 선택을 같은 전투에서 다시 열 때 유지하는 흐름.

## 2026-10-14 — 전투 스탯 분류·검색과 스크롤 탐색

- 이번 주제: 전투 스탯을 병력·구조물·전투 규칙으로 나누고 이름·효과 검색과 출전 덱 필터, 줄바꿈·키보드 탐색으로 긴 설명을 쉽게 읽는다.
- 시작 상태: Git 명령 없이 인덱스와 추적 파일의 원본/LF 해시, HEAD/인덱스 트리 해시를 직접 비교했다. 미커밋 변경·충돌·미추적 소스·문서가 없어 중단 작업은 없었다.

- 확인한 불편: 병력 카드는 너비 455의 고정 2열이었고, 구조물·전장 설명은 스크롤 밖의 줄바꿈 없는 텍스트였다. 원하는 항목만 찾거나 온라인에서 Esc로 닫기 어려웠다.
- 병력·구조물·전투 규칙 분류 버튼을 추가했다. 검색칸·필터·닫기는 스크롤 밖에 유지하고 설명 카드만 스크롤한다.
