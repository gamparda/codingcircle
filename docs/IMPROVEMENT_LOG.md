# 프로젝트 개선 기록

## 2026-10-13 — 진행도 복구 전 시작 목표·튜토리얼 상태 비교

- 이번 주제: 사본 선택·가져오기·최종 복구 확인에서 시작 목표별 완료 변화와 튜토리얼 완료 상태를 비교해 다시 해야 할 항목을 미리 안내한다.
- 시작 상태: Git 명령 없이 인덱스·추적 파일 해시와 HEAD·인덱스 루트 트리를 비교했다. 미커밋 변경과 미추적 소스·문서는 없었다.
- 최근 3회차와 아카이브의 다음 후보를 읽고 남아 있던 시작 목표·튜토리얼 복구 비교를 선택했다. 소스 수정 전에 주제를 로그에 기록했다.
- 확인한 문제: 사본으로 복구하면 목표·튜토리얼 완료 기록도 바뀌지만, 기존 비교에는 이 변화가 표시되지 않았다.
- 시작 목표별 현재·사본 완료 여부를 비교하고 다시 미완료로 바뀌는 목표의 이름·안내를 먼저 표시한다.
- 완료 총수가 같거나 늘어도 기존 완료 목표의 상실을 따로 경고한다. 다른 목표의 증가로 상쇄하지 않는다.
- 새로 완료되는 목표는 손실 목록 뒤에 표시하며, 상태 유지 개수와 변경 없음도 안내한다.
- 실제 메뉴의 Goals.is_done을 재사용한다. 첫 승리·일일 도전·온라인 대전은 누적 전적으로 판정한다.
- 내 덱 만들기·드래프트·리플레이 보기는 저장된 목표 완료 기록으로 판정한다. 오늘의 도전 기록·업적 개수로 추정하지 않는다.
- 목표 제목·안내·전체 개수와 다음 추천은 기존 Goals 정의·함수를 사용한다. 목표 판정 규칙과 완료 기록을 바꾸지 않는다.
- 현재 → 사본의 다음 추천을 표시한다. 모든 목표 완료 여부가 바뀌면 메인 메뉴 시작 목표 버튼의 표시·숨김 변화도 설명한다.
- 튜토리얼 완료 상태를 별도로 비교한다. 완료가 안내 수행 또는 건너뛰기를 뜻하며 승리 여부와 별개임을 안내한다.
- 완료 → 미완료이면 다음 캠페인·AI 연습에서 소환·설치·자원 회복 안내가 다시 표시되고 건너뛸 수 있음을 경고한다.
- 미완료 → 완료이면 첫 전투 안내를 자동 표시하지 않는다고 설명한다. 같은 상태에는 변경 없음을 표시한다.
- 공통 비교에 연결해 사본 선택·클립보드 가져오기·최종 복구 확인 세 화면에서 동일하게 표시한다.
- 손실은 경고색과 글자로 구분하고 기존 세로 스크롤·줄바꿈을 사용한다. 새 조작 버튼이나 초점 정지점은 추가하지 않는다.
- 실제 복구와 같은 정규화된 데이터를 읽기만 한다. 원본·사본·현재 진행도, 복구 전 보관·지문 확인·저장 실패 처리는 유지한다.
- README를 갱신하고 이전 1회차를 아카이브로 옮겨 최근 3회차만 남겼다. 완료 판정·튜토리얼 진입·세 화면 연결·변경 범위를 소스로 검토했다.
- 테스트는 추가·수정·실행하지 않았고 게임 실행·렌더링도 하지 않았다. 실제 로드·표시·조작 검증은 외부 스크립트에 맡긴다.
- 호환성 변경: 없음. RPC 시그니처·세이브·서버 파일 형식을 유지한다. 버전 번호·release.json·CHANGELOG·PatchNotes는 수정하지 않았고 Git 명령은 실행하지 않았다.
- 다음 후보: 도전 보관 전투의 병력·구조물 이름 검색, 코드로 연 전투 재생 후 입력 코드와 진입 버튼 초점 복원, 진행도 복구 전 닉네임·새 기능 확인 상태의 변화 안내.

## 2026-10-13 — 온라인 전투 다운로드 취소와 즉시 재선택

- 이번 주제: 최근 온라인 전투와 코드 열기에서 창을 닫지 않고 다운로드를 취소하고, 늦은 응답의 재생을 막으며 다른 전투를 바로 선택한다.
- 시작 상태: Git 명령 없이 인덱스·추적 파일 해시와 HEAD·인덱스 루트 트리를 비교했다. 미커밋 변경과 미추적 소스·문서는 없었다.
- 최근 3회차와 아카이브의 다음 후보를 읽고 아직 남아 있던 다운로드 취소를 선택했다. 소스 수정 전에 주제를 로그에 먼저 기록했다.
- 확인한 문제: 접속·응답을 기다리는 동안 다른 전투를 선택하려면 창을 닫고 다시 열거나 응답 시간 초과를 기다려야 했다.
- 최근 온라인 전투의 고정 하단에 불러오기 취소 버튼을 추가했다. 다운로드가 진행 중일 때만 표시하고 터치 최소 높이 58을 적용한다.
- 취소하면 모든 보기 버튼을 즉시 다시 사용할 수 있다. 같은 전투를 다시 보거나 다른 전투를 선택할 수 있고 목록 창은 유지한다.
- 취소 안내를 요청 코드와 함께 상단·해당 카드에 표시한다. 실패와 구별하며 검색으로 숨겨지거나 새로고침으로 교체된 카드에도 상태를 다시 적용한다.
- 코드로 열기에도 불러오기 취소를 추가했다. 취소 후 입력한 코드를 유지하고 입력·열기 잠금을 해제해 코드를 바로 바꿀 수 있다.
- 코드 창의 열기·취소를 같은 행에 배치해 취소 버튼이 표시될 때 창의 세로 공간을 더 차지하지 않도록 했다.
- 취소는 해당 창이 소유한 다운로드만 해제한다. 타이머·응답 신호·콜백을 먼저 정리하고 나서 화면의 조작 잠금을 푼다.
- 취소한 요청의 늦은 응답은 재생기로 연결하지 않는다. 서버에 이미 보낸 전송을 되돌리지는 않으며 공유 연결과 별도 목록 조회는 유지한다.
- 접속 완료·실패 콜백은 요청의 약한 참조와 트리 수명을 확인한다. 취소·화면 종료로 제거한 요청을 호출하거나 뒤늦게 전송하지 않는다.
- 최근 목록의 Tab 순환에 진행 중인 취소 버튼을 포함한다. 취소·실패 후에는 보이는 선택 카드의 보기 또는 목록 스크롤로 초점을 돌린다.
- 코드 창도 Tab 순환에서 잠긴 입력·열기와 숨긴 취소를 건너뛰고 Esc로 닫는다. 취소·실패 후 취소 버튼의 초점은 코드 입력으로 복원한다.
- 기존 검색·필터·목록 새로고침·재생 후 복귀, 코드 발급·업로드 응답 보호와 로컬 보관 경로는 유지한다.
- README를 갱신하고 이전 1회차를 아카이브로 옮겨 최근 3회차만 남겼다. 요청 소유권·접속 콜백·늦은 응답·카드 교체·키보드 이동을 소스로 검토했다.
- 테스트는 추가·수정·실행하지 않았고 게임 실행·렌더링도 하지 않았다. 실제 로드·표시·조작 검증은 외부 스크립트에 맡긴다.
- 호환성 변경: 없음. RPC 시그니처·세이브·서버 파일 형식을 유지한다. 버전 번호·release.json·CHANGELOG·PatchNotes는 수정하지 않았고 Git 명령은 실행하지 않았다.
- 다음 후보: 복구 비교에서 시작 목표·튜토리얼 완료 상태의 변화 안내, 도전 보관 전투의 병력·구조물 이름 검색, 코드로 연 전투 재생 후 입력 코드와 진입 버튼 초점 복원.

## 2026-10-13 — 도전 보관 전투의 양쪽 덱 구성 사전 표시

- 이번 주제: 도전 보관 전투 카드에 내 덱·상대 덱의 병력과 구조물을 표시해 재생 전에 원하는 전투를 찾는다.
- 시작 상태: Git 명령 없이 인덱스와 추적 파일 해시를 비교했다. 미커밋 추적 파일 변경과 미추적 파일은 없었으며 HEAD·인덱스의 루트 트리도 같았다.
- 최근 3회차와 아카이브의 다음 후보를 읽고 남아 있던 도전 전투의 덱 미리보기를 선택했다. 소스 수정 전에 주제를 로그에 기록했다.
- 확인한 문제: 도전 전투 카드에 결과·시간·점수만 있어 사용한 병력·구조물을 확인하려면 전투를 재생해야 했다.
- 카드마다 내 덱 (블루)과 상대 덱 (레드)을 별도로 표시한다. 양쪽 진영은 이름과 기존 진영색을 함께 사용해 구분한다.
- 각 병력의 기존 초상화와 이름을 함께 표시한다. 아이콘만으로 병력을 추측하거나 툴팁을 열 필요가 없다.
- 구조물은 별도 행에 모든 이름을 표시한다. 이름은 기존 데이터 리소스의 표시 이름을 재사용한다.
- 병력 이름도 기존 전투 데이터의 이름을 사용하며 방패 병력의 초상화는 기존 tanker 자산을 사용한다.
- 화면이 좁아지면 병력 항목을 다음 줄로 넘기고 구조물 이름도 줄바꿈한다. 카드 내용은 기존 세로 스크롤 안에 유지한다.
- 초상화와 장식 컨테이너는 마우스·터치 입력을 가로채지 않도록 설정한다. 새 버튼이나 키보드 초점 정지점은 추가하지 않는다.
- 덱은 리플레이의 최초 설정을 복사해 표시한다. 현재 선택한 덱·오늘 생성한 도전·현재 AI 단계 덱으로 대체하지 않는다.
- 일일·주간 도전과 이전·버전 미상 전투에도 동일하게 적용한다. 클립은 원본 전체 전투의 출전 덱을 보여 준다.
- 덱 구성이 실제 생산 병력 수나 설치 구조물 수가 아님을 선택 창에 안내한다. 승패·시간·점수 일치만으로 최고 점수 전투를 확정하지 않는 안내도 유지한다.
- 전투 선택 창용 조회에만 양쪽 병력·구조물 배열을 추가한다. 전적 화면의 개수 조회는 기존의 작은 메타데이터만 유지한다.
- 명령 기록·플레이어·전체 설정을 카드에 보관하지 않는다. 점수 분석과 파일 지문은 원본 전체 전투를 대상으로 하는 기존 경로를 유지한다.
- 새로고침·재생 후 복귀에서도 다시 읽은 덱을 표시하며 기존 분석 요약·스크롤·선택 카드 초점 복원을 유지한다.
- 재생·점수 분석 직전의 파일 변경 확인, 버전별 그룹과 최신 보관순, Tab·Esc·방향키 조작은 기존 코드를 유지한다.
- README에 미리보기 안내를 추가하고 이전 1회차를 아카이브로 옮겨 최근 3회차만 남겼다. 데이터 유효성·진영 배정·자산 경로·조회 호출·화면 연결을 소스로 검토했다.
- 테스트는 추가·수정·실행하지 않았고 게임 실행·렌더링도 하지 않았다. 실제 로드·표시·터치 조작 검증은 외부 스크립트에 맡긴다.
