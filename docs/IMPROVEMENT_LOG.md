# 프로젝트 개선 기록

## 2026-10-14 — 전장 상태 카드의 터치 탐색과 닫기

- 이번 주제: 움직이는 겹침 대상을 상태 카드의 이전·다음 버튼으로 비교하고, 닫기 버튼으로 전장 조작에 복귀한다.
- 시작 상태: Git 명령 없이 인덱스와 작업 파일의 원본/LF 해시를 비교하고, 인덱스로 재구성한 트리 해시와 loose HEAD 커밋의 트리 해시를 대조했다. 미커밋·스테이징·충돌 변경은 없었으며 미추적 후보는 무시 대상인 Python 캐시뿐이었다.
- 최근 3회차와 아카이브의 전체 주제·남아 있는 다음 후보를 읽었다. 키보드 순환은 구현됐지만 움직이는 대상을 터치로 비교하기 어려운 문제를 선택했다.
- 소스 수정 전에 이번 주제 한 줄을 먼저 기록했다. PowerShell 파이프에서 한글이 손상된 것을 발견해 UTF-8 패치로 주제 기록을 바로잡았다.
- 확인한 불편: 상태 카드에 탐색·닫기 터치 조작이 없어 밀집한 병력을 반복해서 겨냥하거나 빈 전장을 찾아 눌러야 했다.
- 병력·구조물 카드에 높이 58의 이전·다음·닫기 버튼을 추가했다. 누름·마우스 호버·비활성 상태를 색으로 구분하고 동작 완료 시 기존 UI 효과음을 사용한다.
- 다음 버튼에 현재 겹침 순서와 후보 수를 표시한다. 후보가 하나뿐이면 이전·다음을 비활성화하고 대상 1개 안내와 닫기 버튼을 유지한다.
- 버튼에 Tab·Shift+Tab·Esc 안내를 표시한다. 기존 반복 클릭·터치 순환, 단일 대상 재선택, 빈 전장 닫기와 키보드 순환 규칙을 유지한다.
- 카드의 가로 위치를 최초 선택 위치 기준으로 고정한다. 병력 이동·온라인 보간·앞뒤 대상 전환에도 연결선만 실제 대상을 따라가고 버튼은 움직이지 않는다.
- 병력이 포함된 후보 목록은 병력 카드 높이를 예약한다. 구조물로 전환하거나 이웃 병력이 사라져도 버튼 행이 위아래로 이동하지 않는다.
- 다른 전장 대상을 직접 선택하면 새 기준 위치와 카드 높이를 정한다. 화면 폭에 맞춰 카드 폭·위치를 제한하고 화면 크기가 바뀐 도중의 버튼 조작은 취소한다.
- 카드 전체를 먼저 판정해 설명·여백·비활성 버튼을 눌러도 뒤의 병력·구조물을 선택하거나 선택 정보를 닫지 않는다.
- 버튼의 포인터 입력은 기존 전장 선택 소유권을 사용하며 손을 뗄 때만 실행한다. 누른 영역 이탈·14픽셀 초과 이동·OS 취소·추가 손가락/버튼·중간 키 입력은 동작을 취소한다.
- 이전·다음 대상은 누르는 순간 종류와 ID로 고정한다. 놓기 전에 그 대상이 사망·파괴·만료되면 다른 이웃을 대신 선택하지 않는다.
- 선택 원본과 버튼 영역도 놓는 순간 다시 확인한다. 일시정지·모달·채팅·건설·설치 대기·연결 복구·앱 이탈·시간 되돌림·종료에는 기존 취소 경로를 공유한다.
- 터치 에뮬레이션 마우스 누름·해제 소비를 유지한다. 카드에서 시작한 조작을 HUD 위에서 끝내도 구매·설치로 이어지지 않도록 Main의 종료 포착을 재사용한다.
- 병력 체력·공격력·분노·저주·지원·소환 시간, 구조물 체력·수명·수입은 기존 최신 스냅샷 계산을 유지한다. 전투 모델·통신·저장 데이터는 변경하지 않는다.
- 병력·구조물 현황 툴팁과 README에 터치 탐색·고정 위치·비활성 조건·취소 동작을 추가했다. 소스로 카드 배치·후보 생존·ID 구분·누름/해제·화면 수명 경로를 검토했다.
- 테스트 추가·수정·실행과 게임 실행·로드 검사·렌더링은 하지 않았다. 실제 로드·터치/마우스·병력/구조물 전환·대상 사망·배속·관전·재접속·화면 배치는 외부 스크립트에 맡긴다.
- 호환성 변경: 없음. RPC 시그니처·세이브·서버 파일 형식과 버전 번호·release.json·CHANGELOG·PatchNotes를 유지했다. Git 명령은 실행하지 않았으며 가장 오래된 회차를 아카이브로 옮겨 최근 3회차만 남긴다.
- 다음 후보: 전장 상태 카드에서 해당 종류의 스탯 상세로 바로 이동, 복구 비교의 특정 감소 경고에서 상세로 바로 이동, 도전 보관 전투 검색 결과의 페이지 번호 직접 이동.

## 2026-10-14 — 겹친 전장 대상의 순환 선택

- 이번 주제: 밀집한 병력과 그 아래 구조물을 같은 위치의 반복 클릭·터치로 차례로 확인하고, 선택 순서·대상 수를 안내한다.
- 시작 상태: Git 명령 없이 인덱스와 작업 파일의 원본/LF 해시, loose 객체에서 읽은 HEAD 트리와 재구성한 인덱스 트리를 비교했다. 미커밋·스테이징 변경·충돌·미추적 파일이 없어 중단 작업은 없었다.
- 최근 3회차와 아카이브 주제·다음 후보를 읽고 전투 중 밀집 병력을 확인하는 조작을 선택했다. 구현 전에 이번 주제를 UTF-8 패치로 먼저 기록했다.
- 확인한 불편: 겹친 병력은 가까운 한 명만 선택되고 재선택하면 닫혀, 다른 병력이나 아래 구조물의 현재 상태를 직접 확인하기 어려웠다.
- UnitInspection은 누른 위치의 살아 있는 병력을 거리순으로 모으며, 같은 거리에서는 기존처럼 앞에 그려진 병력을 우선한다.
- StructureInspection은 병력 다음에 해당 위치의 구조물 후보를 추가한다. 첫 선택의 병력 우선·가까운 구조물 우선·동거리 판정을 유지한다.
- 이미 선택한 대상이 누른 위치에 있고 후보가 둘 이상이면 다음 후보로 전환한다. 마지막 후보 다음에는 처음으로 돌아오며, 병력 아래 가려진 구조물도 선택한다.
- 다시 눌렀을 때 아직 그 위치에 있는 기존 후보의 순서를 보존하고 새 후보는 뒤에 추가해, 이동·보간·스냅샷 순서 변경으로 순환 순서가 뒤섞이지 않게 한다.
- 선택 대상이 없는 다른 위치에서는 기존 우선순위로 새 후보 목록을 만든다. 누른 위치에 대상이 하나뿐이면 같은 대상 재선택으로 닫는 동작을 유지한다.
- 겹친 대상을 선택한 동안 Tab은 다음, Shift+Tab은 이전 후보로 순환한다. 마지막으로 선택한 후보 목록을 따라가므로 병력이 움직여도 앞뒤로 비교한다.
- 키 반복 입력은 순환하지 않으며 Ctrl·Alt·Meta 조합은 가로채지 않는다. 후보가 하나뿐이거나 정보가 닫혔을 때의 기존 Tab 초점 이동을 유지한다.
- 병력·구조물 상태 카드에 겹침 N/M과 다음·이전·닫기 안내를 표시한다. 겹친 후보가 있는 카드만 높이를 늘려 기존 체력·효과·수명 설명과 분리한다.
- 후보는 진영이 아니라 병력/구조물 종류 공간과 ID로 구분한다. 아군·적군·소환 병력·관전과 동일 숫자 ID의 서로 다른 대상도 함께 다룬다.
- 사망·파괴·만료로 사라진 후보는 최신 스냅샷에서 제외하고 순서·개수를 갱신한다. 선택한 대상 자체가 사라지면 기존처럼 정보와 후보 목록을 닫는다.
- 후보 순서 유지와 생존 확인은 종류별 ID 조회를 사용한다. 후보마다 전체 스냅샷을 반복 탐색하지 않으며 전투 상태·타이머·모델 수치는 변경하지 않는다.
- 누르는 순간 순환 대상을 고정하고, 놓을 때 같은 대상의 영역 안인지 확인한다. 드래그·전장 밖 해제·OS 취소·다른 손가락/버튼·중간 키 입력은 순서를 진행하지 않는다.
- 건설·설치 대기·일시정지·모달·채팅·상태 수신 대기·연결 복구·앱 이탈·시간 되돌림·종료에서는 후보도 정리한다. 터치 에뮬레이션 소비와 기존 생산·설치·리플레이 조작을 유지한다.
- 병력·구조물 현황 툴팁과 README에 순환 선택·후보 수·키보드 조작을 추가했다. 소스로 ID 구분·거리 동률·순서 보존·후보 제거·포인터 해제·카드 배치를 검토했다.
- 테스트 추가·수정·실행과 게임 실행·로드 검사·렌더링은 하지 않았다. 실제 로드·밀집 병력/구조물·Tab/Shift+Tab·터치/마우스·배속·관전·재접속·화면 배치는 외부 스크립트에 맡긴다.
- 호환성 변경: 없음. RPC 시그니처·세이브·서버 파일 형식과 버전 번호·release.json·CHANGELOG·PatchNotes를 유지했다. Git 명령은 실행하지 않았다. 가장 오래된 회차를 아카이브로 옮겨 최근 3회차만 남겼다.
- 다음 후보: 전장 상태 카드에서 이전·다음 대상을 터치 버튼으로 전환하는 조작, 복구 비교의 특정 감소 경고에서 상세로 바로 이동하는 흐름, 도전 보관 전투 검색 결과의 페이지 번호 직접 이동.

## 2026-10-14 — 전장 병력 직접 선택과 전투 상태 확인

- 이번 주제: 움직이는 병력을 클릭·터치해 현재 체력·분노·저주·공속 지원 상태를 전투를 멈추지 않고 확인한다.
- 시작 상태: Git 명령 없이 인덱스와 작업 파일의 원본/LF 해시, 재구성한 인덱스 트리와 HEAD 트리를 대조했다. 미커밋·스테이징 변경·충돌·미추적 파일이 없어 중단 작업은 없었다.
- 최근 3회차·아카이브 주제·다음 후보를 읽고 실제 전투에서 자주 마주치는 개별 병력 상태 확인을 선택했다. 소스 수정 전에 주제를 먼저 기록했다.
- 확인한 불편: 전장은 작은 체력 막대·광폭/저주 표식만 표시하고, 병력 현황은 종류별 인원·일반 스탯을 보여 주어 개별 병력의 현재 수치를 읽기 어려웠다.
- UnitInspection에 병력 좌표·클릭 판정·읽기 전용 카드 그리기를 모으고, 기존 StructureInspection의 입력 소유권·취소·화면 수명 경로를 함께 사용한다.
- 건설 선택이 없을 때 양쪽 병력 본체·체력 막대를 클릭·터치해 선택한다. 겹치면 가까운 본체, 같은 거리면 앞에 그려진 병력을 고르고 구조물보다 병력을 우선한다.
- 병력과 구조물의 ID 공간을 구분해 숫자 ID가 같아도 혼동하지 않는다. 누름 뒤 다른 병력이 더 가까워져도 놓는 위치가 원래 병력 영역 안이면 원래 ID를 선택한다.
- 금색 테두리·발밑 표식·연결선과 전장 위쪽 상태 카드로 선택 대상을 표시한다. 위치는 기존 화면 반전·온라인 위치 보간을 따라가며 전투 수치는 보간하지 않는다.
- 현재/최대 체력·비율·막대와 현재 공격력·공속 배율을 표시한다. 체력 25% 이하는 사망 주의를 색상과 문구로 함께 강조한다.
- 공격력은 실제 병력의 성장 반영 damage와 현재 위치의 저주 감소율을 사용한다. 공속은 지원 중첩과 분노 배율을 곱해 전투 판정과 같은 기준으로 표시한다.
- 지원 중첩은 0~최대 범위로 표시하고, 마법사는 직접 공격하지 않는 공속 지원 병력이며 지원 효과를 받지 않는다고 안내한다.
- 저주는 상대 진영·현재 위치·만료 전투 시각으로 판정한다. 중첩 장판의 감소율은 한 번만 적용하고 모든 유효 장판이 만료되기까지의 시간과 벗어나면 해제됨을 안내한다.
- 광전사는 분노 발동 여부·공속 배율 또는 발동 체력 기준을 표시한다. 네크로맨서는 받은 summon_remaining으로 다음 해골 소환 시간을 표시하고 누락 시 정보 없음으로 안내한다.
- 소환된 해골도 선택할 수 있으며 소환 병력이라고 표시한다. 관전은 블루·레드 이름을 사용하며 최신 스냅샷으로 같은 병력의 상태를 갱신한다.
- 실제 시간으로 타이머를 줄이지 않아 배속·수신 지연에도 전투 시간 기준을 유지한다. 병력 사망·제거·전투 시각 되돌림에는 이전 선택을 버린다.
- 같은 병력 재선택·빈 전장·Esc로 닫고 병력/구조물 사이에 바로 전환한다. 드래그·전장 밖 해제·OS 취소·다른 손가락/버튼·키 입력의 선택 취소를 유지한다.
