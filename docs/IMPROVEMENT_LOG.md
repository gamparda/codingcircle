## 2026-10-13 — 사본 복구 전후 도전 기록의 날짜·버전별 비교

- 이번 주제: 진행도 사본 선택·가져오기·복구 확인에서 일일·주간 도전 기록의 추가·변경·삭제와 낮아지는 기록을 날짜·버전별로 확인한다.
- 시작 상태: Git 명령 없이 추적 파일·인덱스 해시 및 HEAD·인덱스 루트 트리를 비교했다. 미커밋 변경과 미완료 소스·문서는 없었다.

- 확인한 문제: 사본의 도전 날짜 개수만 표시해 개수가 같아도 어느 날짜·버전의 성공 기록이 사라지거나 낮아지는지 알 수 없었다.
- 기존 캠페인·덱 비교에 일일·주간 도전 비교를 추가했다. 사본 선택·클립보드 가져오기 확인·최종 복구 확인에서 동일한 비교를 사용한다.
- 실제 복구에 사용하는 정규화된 현재 진행도와 사본을 비교하며 원본·진행도·서버 기록을 수정하지 않는다.
- 날짜별 주 기록과 previous의 버전별 기록을 같은 날짜·버전 단위로 펼친다. 주 기록/이전 기록의 저장 위치만 바뀐 경우에는 변경으로 세지 않는다.
- 일일·주간별 추가·변경·사라짐·동일 개수를 표시하고, 변경된 기록마다 현재와 사본의 성공 여부·점수·전투 시간을 나란히 안내한다.
- 한 날짜가 여러 버전이면 별도 기록으로 표시한다. 주간은 월요일 날짜를 표시하고 버전 미상은 동일 규칙이라고 확정할 수 없음을 안내한다.
- 사라지는 기록과 성공→실패·점수 감소·동점의 느린 시간은 상단 경고로 표시한다. 다른 날짜·버전에서 증가한 기록으로 상쇄하지 않는다.
- 점수가 오른 성공 기록의 느린 시간과 실패 기록의 시간 변화는 성공 기록 하락으로 세지 않는다. 유효한 0초도 기록 없음과 구분한다.
- 변경된 기록의 날짜·버전·일일/주간·성공/실패 검색과 전체 변경·사라짐/낮아짐·추가만·변경만 필터를 추가했다.
- 하이픈 날짜와 YYYYMMDD 검색을 지원하고, 공백으로 나눈 검색어를 모두 포함하는 기록만 표시한다. 검색·필터는 파일을 다시 읽지 않는다.
- 한 페이지에 8개씩 표시하고 조건 변경 시 첫 페이지로 이동한다. 필터 결과 개수·전체 변경 개수·페이지와 빈 결과 안내를 표시한다.
- 필터·페이지 버튼의 최소 높이는 58이며 좁은 화면에서 줄바꿈한다. 확인창의 Tab 순환에 새 컨트롤을 포함하고 Esc·기존 키보드 스크롤을 유지한다.
- 검색 입력·변경 유형 선택의 자체 방향키 조작을 유지한다. 사본을 다시 선택하면 비교와 검색·페이지를 새 사본 기준으로 초기화한다.
- README를 갱신하고 이전 1회차를 아카이브로 옮겨 최근 3회차만 남겼다. 정규화·버전별 대응·하락 조건·세 화면의 연결·키보드 흐름을 소스로 검토했다.
- 테스트는 추가·수정·실행하지 않았고 게임 실행·렌더링도 하지 않았다. 실제 로드·표시·조작 검증은 외부 스크립트에 맡긴다.
- 호환성 변경: 없음. RPC 시그니처·세이브·서버 파일 형식을 유지한다. 버전 번호·release.json·CHANGELOG·PatchNotes는 수정하지 않았고 Git 명령은 실행하지 않았다.
- 다음 후보: 도전 보관 전투 재생 후 분석 카드로 바로 복귀하는 흐름, 최근 온라인 전투 목록 새로고침 중 개별 보기 요청 상태 안내, 복구 비교에서 전적·업적의 구체적인 감소 안내.

## 2026-10-13 — 도전 보관 전투의 점수 분석과 최고 기록 비교

- 이번 주제: 도전 리플레이를 선택 창에서 분석해 기지 체력·완료 시간의 점수 근거와 최고 기록 차이를 확인한다.
- 이어서 마무리: 분석 중 전투 이벤트 누적을 막고, 새로고침에도 분석 결과·선택 위치를 유지하며 중단된 기록을 완성한다.
- 시작 상태: Git 명령 없이 추적 파일·인덱스 해시와 HEAD·인덱스 루트 트리를 읽어 미커밋 변경이 없음을 확인했다. 이번 주제만 적힌 중단 기록과 이미 반영된 관련 코드를 먼저 검토했다.
- 최근 3회차와 아카이브의 다음 후보를 읽었다. 새 주제를 중복 구현하지 않고 도전 점수 분석 회차를 마무리했다.
- 보관 전투 카드의 점수 분석에서 내 기지 체력·전체 전투 시간과 기본 점수·체력 가점·시간 감점·반올림·최솟값/최댓값 적용을 표시한다.
- 종료 상태 해시·승패·틱 수·완료 시간이 저장 결과와 일치할 때만 점수를 표시한다. 패배·무승부는 0점이다.

- 결과·시간·점수가 모두 같아도 같은 전투라고 확정하지 않는다. 클립 분석은 전체 전투의 종료 점수임을 안내한다.
- 선택한 전투만 프레임마다 최대 120틱·약 5ms씩 분석하며 취소·다른 전투 분석·새로고침·닫기·재생으로 중단한다.
- 마무리 중 발견한 문제: 분석용 모델에서 쓰지 않는 전투 이벤트가 누적됐고 새로고침 시 완료된 분석과 스크롤이 사라졌다.
