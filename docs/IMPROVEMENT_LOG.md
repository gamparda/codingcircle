## 2026-10-14 — 양쪽 구조물의 설치·체력 현황 비교

- 이번 주제: 전투 중 구조물 현황을 터치로 열어 양쪽 설치 수·종류별 한도·남은 체력·발전기 수입을 비교한다.
- 시작 상태: Git 명령 없이 인덱스·추적 파일의 원본/LF 해시와 느슨한 객체·팩 객체의 HEAD 트리를 직접 대조했다. 미커밋 변경·충돌·미추적 소스·문서가 없어 중단 작업은 없었다.
- 최근 3회차와 아카이브의 주제·다음 후보를 읽고 실제 전투의 구조물 비교를 선택했다. 구현 전에 이번 주제를 한 줄 먼저 기록했다.
- 확인한 불편: 기존 구조물 표시는 내 진영의 총 설치 수만 알려 상대의 발전기·포탑 구성과 개별 파괴 위험을 터치 화면에서 비교하기 어려웠다.
- 전장 오른쪽 아래의 구조물 수를 240×58 터치 버튼으로 확장했다. 상세 열기 표시·툴팁·키보드 초점을 제공하고 구매 카드와 전장 크기를 유지한다.
- 새 상세 화면에서 양쪽 방벽·늪·포탑·발전기 수를 나란히 표시한다. 없는 종류도 0개로 남겨 수치 변경 중 비교 위치가 바뀌지 않는다.
- 진영 전체 설치 한도와 종류별 한도를 기존 모델·리소스에서 읽고 한도에 도달한 항목을 강조한다. 파괴·수명 종료 후 빈자리 재설치 조건도 안내한다.
- 살아 있는 구조물만 집계하고, 각 진영 최대 3개의 개별 체력과 막대를 표시한다. 체력 25% 이하에는 색상과 파괴 주의 문구를 함께 표시한다.
- 개별 구조물은 설치 순서로 정렬하고 후방 0%→전방 100%의 건설 구역 위치를 표시한다. 오른쪽 진영에서는 좌표 방향을 뒤집어 같은 기준으로 비교한다.
