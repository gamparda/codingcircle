## 2026-10-14 — 전장 현황에서 종류별 스탯 바로 확인

- 이번 주제: 병력·구조물 현황의 종류를 눌러 해당 스탯 설명을 열고 원래 현황의 위치·초점으로 돌아온다.
- 시작 상태: Git 명령 없이 인덱스·작업 파일의 원본/LF 해시와 느슨한 객체·팩 객체의 HEAD 트리를 직접 대조했다. 미커밋·스테이징 변경이 없어 중단된 작업은 없었다.
- 최근 3회차와 아카이브의 주제·다음 후보를 확인하고 남아 있던 종류별 설명 바로가기를 선택했다. 주제 선기록을 시도했으나 PowerShell 인코딩 오류로 반영되지 않아 최종 정리에서 원본 기록을 복구하고 UTF-8로 바로잡았다.
- 확인한 불편: 현황에서 상대 병력·구조물을 본 뒤 능력·설치 조건을 확인하려면 전체 스탯을 열어 분류와 설명을 다시 찾아야 했다.
- 병력 현황의 종류 이름을 높이 58의 터치 버튼으로 바꾸고 해당 종류의 양쪽 스탯 비교로 연결했다.
- 진영별 병력 수도 터치 버튼으로 만들어 해당 진영의 성장 반영 수치를 바로 확인하도록 했다. 소환 병력·생존 수 0인 종류도 열 수 있다.
- 구조물 현황의 양쪽 종류별 수·한도 표시를 높이 58의 버튼으로 바꾸고 해당 진영의 체력·비용·설치 한도·효과 설명으로 연결했다.
- 종류 ID와 분류로 목표 카드를 찾아 배치가 끝난 뒤 그 설명으로 스크롤한다. 이름 부분 검색으로 비슷한 종류를 잘못 선택하지 않는다.
- 선택한 카드는 금색 테두리와 ‘현황에서 선택’ 문구로 표시한다. 전체 분류·검색·진영 변경도 계속 사용할 수 있다.
- 내 진영이 오른쪽인 온라인 전투와 관전의 블루·레드를 실제 진영에 맞춰 연결한다. 미확인 상대 덱에서는 기존 기본 수치·비교 제한 안내를 유지한다.
- 바로가기 스탯은 별도 임시 탐색 상태를 사용해 기존 유닛 스탯의 검색어·분류별 위치·필터·초점 기록을 덮어쓰지 않는다.
- 하단의 ‘현황으로 돌아가기’와 Esc는 원래 병력·구조물 현황을 다시 열고 선택한 진영·스크롤·버튼 초점을 복원한다.
- ‘전장으로 닫기’를 별도로 제공하고 바로 닫을 때도 원래 기지·구조물 현황 버튼으로 초점을 돌린다. 펼친 진영 메뉴에서 Esc는 메뉴를 먼저 닫는다.
- 현황 복원은 컨테이너 배치와 초점 스크롤이 끝난 뒤 적용한다. 터치·클릭·휠·키 입력을 시작하면 사용자 조작을 우선해 지연 복원을 취소한다.
- 결과·화면 교체·앱 이탈의 자동 정지·다른 확인창을 검사해 삭제된 창을 갱신하거나 현황을 다시 열지 않는다. 기록에는 노드 참조 대신 위치·버튼 이름만 보관한다.
- 기존 전투 모달 경로를 재사용해 오프라인 모델·전장 정지를 유지한다. 온라인 상태 갱신·구매 입력 잠금과 선택한 구조물·이미 전송한 설치 확인을 유지한다.
- 기존 집계와 표시 노드를 계속 사용하고 값이 바뀔 때만 문구를 갱신한다. 별도 서버 요청·타이머·파일 저장은 추가하지 않았다.
- README에 사용법을 반영하고 가장 오래된 1회차를 아카이브로 옮겨 최근 3회차만 남겼다. 호출·진영·목표 카드·복원·입력·모달 수명 경로를 소스로 검토했다.
- 테스트는 추가·수정·실행하지 않았고 게임 실행·렌더링도 하지 않았다. 실제 로드·터치·진영 선택·빠른 복귀·배치·재접속 검증은 외부 스크립트에 맡긴다.
- 호환성 변경: 없음. RPC 시그니처·세이브·서버 파일 형식·전투 규칙·밸런스와 버전 번호·release.json·CHANGELOG·PatchNotes를 유지했다. Git 명령은 실행하지 않았다.
- 다음 후보: 도전 보관 전투 선택 창의 개별 검색 조건 해제, 복구 비교에서 특정 감소 경고의 상세로 바로 이동하는 흐름, 병력 현황에서 생산 대기·자원 부족을 함께 확인하는 안내.

## 2026-10-14 — 양쪽 구조물의 설치·체력 현황 비교

- 이번 주제: 전투 중 구조물 현황을 터치로 열어 양쪽 설치 수·종류별 한도·남은 체력·발전기 수입을 비교한다.
- 시작 상태: Git 명령 없이 인덱스·추적 파일의 원본/LF 해시와 느슨한 객체·팩 객체의 HEAD 트리를 직접 대조했다. 미커밋 변경·충돌·미추적 소스·문서가 없어 중단 작업은 없었다.
- 최근 3회차와 아카이브의 주제·다음 후보를 읽고 실제 전투의 구조물 비교를 선택했다. 구현 전에 이번 주제를 한 줄 먼저 기록했다.
- 확인한 불편: 기존 구조물 표시는 내 진영의 총 설치 수만 알려 상대의 발전기·포탑 구성과 개별 파괴 위험을 터치 화면에서 비교하기 어려웠다.
- 전장 오른쪽 아래의 구조물 수를 240×58 터치 버튼으로 확장했다. 상세 열기 표시·툴팁·키보드 초점을 제공하고 구매 카드와 전장 크기를 유지한다.
- 새 상세 화면에서 양쪽 방벽·늪·포탑·발전기 수를 나란히 표시한다. 없는 종류도 0개로 남겨 수치 변경 중 비교 위치가 바뀌지 않는다.
- 진영 전체 설치 한도와 종류별 한도를 기존 모델·리소스에서 읽고 한도에 도달한 항목을 강조한다. 파괴·수명 종료 후 빈자리 재설치 조건도 안내한다.
- 살아 있는 구조물만 집계하고, 각 진영 최대 3개의 개별 체력과 막대를 표시한다. 체력 25% 이하에는 색상과 파괴 주의 문구를 함께 표시한다.
- 개별 구조물은 설치 순서로 정렬하고 후방 0%→전방 100%의 건설 구역 위치를 표시한다. 오른쪽 진영에서는 좌표 방향을 뒤집어 같은 기준으로 비교한다.
- 늪에는 기존 expires_at과 전투 경과 시간을 이용해 남은 수명을 표시한다. 별도 타이머·로컬 시간 추정 없이 받은 상태를 기준으로 갱신한다.
- 살아 있는 발전기의 추가 수입을 진영별로 표시한다. 수명·수입은 전투 시간 기준임을 안내해 연습 배속의 실제 시간이나 기본·성장 수입과 혼동하지 않게 한다.
- 아군·적군은 실제 own_side를 사용하고, 관전에서는 블루·레드 이름과 진영 색상을 표시한다. 내 진영이 오른쪽이어도 집계와 열 순서를 맞춘다.
- 온라인 전투·관전은 기존 구매 상태·스냅샷 갱신 경로에서 현황을 갱신한다. 입장·재접속·복구 대기에는 오래된 수치와 체력 막대 대신 상태 수신 대기를 표시한다.
- 오프라인에서는 기존 스탯 모달 경로로 모델·전장 애니메이션을 정지한다. 닫기·창 전환·앱 이탈 시 기존 수동 정지·자동 정지·확인창의 우선순위를 유지한다.

- 구조물·병력 현황 사이의 이동과 유닛 스탯 바로가기를 제공한다. 기존 스탯 검색·분류별 읽던 위치 기록을 별도로 덮어쓰지 않는다.

- 열마다 3개의 표시 슬롯을 재사용하고 변경된 문구·색상·막대 값만 갱신한다. 추가 서버 요청·타이머·노드 재생성을 하지 않으며 결과·화면 교체·새 전투에서는 기존 모달 정리 경로를 따른다.
- README에 사용법을 반영했다. 가장 오래된 1회차를 아카이브로 옮겨 최근 3회차만 남기고 소스로 집계·진영·갱신·입력·초점·정지·종료 경로와 호출 API를 검토했다.

## 2026-10-14 — 터치로 확인하는 전장 병력 상세 현황

- 이번 주제: 양쪽 병력 수를 눌러 종류별 생존 수·소환수·공유 한도를 확인하고, 온라인 최신 상태와 오프라인 정지 흐름을 함께 안내한다.
- 시작 상태: Git 명령 없이 인덱스·추적 파일의 원본/LF 해시와 느슨한 객체·팩 객체의 HEAD 트리를 직접 대조했다. 미커밋 변경·충돌·미추적 소스·문서가 없어 중단 작업은 없었다.
- 최근 3회차와 아카이브 주제·다음 후보를 읽고 터치로 병력 현황을 확인하는 흐름을 선택했다. 구현 전에 이번 주제를 한 줄 먼저 기록했다.
- 확인한 불편: 종류별 생존 수는 마우스 툴팁에서만 보여 터치 화면에서는 전체 병력 수 이상의 전력 구성을 확인하기 어려웠다.
- 양쪽 기지 패널 전체를 병력 상세 버튼으로 연결했다. 420×64 영역에서 터치·클릭·키보드로 열며 기존 체력·병력 표시와 툴팁을 유지한다.
- 병력 수 옆에 상세 열기 표시를 추가하고 패널 툴팁에 누르기 안내를 넣었다. 호버·누름 피드백은 반투명으로 표시해 체력과 수치를 가리지 않는다.
- 상세 화면은 양쪽의 종류별 생존 수를 나란히 보여 준다. 출전 여부와 관계없이 알려진 병력 종류를 모두 표시하며 없는 종류는 0명으로 표시한다.
- 양쪽 생존 합계에 소환수 포함 수를 따로 안내하고 해골 행에도 소환 병력임을 표시한다. 아군이 오른쪽 서버 진영이어도 실제 진영 인덱스로 집계한다.
- 관전은 블루·레드 진영 이름을 사용한다. 열 때 누른 진영을 표시하며 양쪽 열·병력 행의 순서를 고정해 수치 갱신 중 탐색 위치가 흔들리지 않는다.
- 전체 점유 수·공유 한도·생존 합계·사망 후 정리 대기를 함께 표시한다. 한도 도달 시 생산 한도를 강조하고 생산·추가 소환 중단과 빈자리 재개 조건을 안내한다.
- 기존 병력 집계 결과를 재사용하고 숫자만 바뀔 때 해당 라벨을 갱신한다. 매 갱신마다 목록을 재생성하거나 추가 모델 순회·서버 요청·타이머를 만들지 않는다.
- 온라인 전투·관전은 기존 스냅샷 갱신 경로에서 최신 현황을 반영한다. 입장·재접속·복구 대기에는 오래된 수치 대신 —와 상태 수신 안내를 표시한다.
- 오프라인은 기존 스탯 모달의 정지 경로를 재사용해 읽는 동안 모델과 전장 애니메이션을 멈춘다. 닫을 때 기존 수동 정지·자동 정지·다른 확인창의 우선순위를 유지한다.
- 열기 전에 진행 중인 터치 설치 동작을 취소한다. 선택한 구조물과 서버에 이미 보낸 설치 확인은 기존 흐름대로 유지하며 상세 화면의 키 입력이 생산 단축키로 전달되지 않는다.
