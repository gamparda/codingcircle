# 프로젝트 개선 기록

## 2026-10-13 — 진행도 복구 전 덱 슬롯 선택과 구성·순서 비교

- 이번 주제: 복구 사본의 세 덱을 슬롯별로 골라 현재·사본의 이름, 병력·구조물 교체와 버튼 순서, 최근 선택 덱 변화를 한눈에 확인한다.
- 시작 상태: Git 명령 없이 인덱스·추적 파일 해시와 HEAD 객체의 루트 트리를 비교했다. 미커밋 변경과 미추적 파일은 없었다.
- 최근 3회차와 아카이브의 다음 후보를 읽고 남아 있던 덱별 복구 비교를 선택했다. 소스 수정 전에 이번 주제를 로그에 먼저 기록했다.
- 확인한 불편: 여러 슬롯의 변경이 긴 텍스트로 이어지고, 빠지는 항목과 순서만 이동하는 항목을 직접 대조해야 했다.
- 세 슬롯의 변경·동일 여부와 현재/사본의 최근 선택 덱을 버튼과 요약에 표시한다. 선택 슬롯은 체크·눌림 상태로 구분한다.
- 처음에는 변경된 첫 슬롯을 보여 준다. 세 덱이 같으면 사본의 최근 선택 덱을 보여 주며, 동일 슬롯도 전체 구성을 확인할 수 있다.
- 슬롯별로 현재 → 사본 이름과 변경 종류를 표시한다. 이름만 변경되거나 최근 선택 덱만 바뀐 경우도 구별한다.
- 병력·구조물별로 사본에서 빠지는 항목과 들어오는 항목을 나누고, 유지되는 항목은 원래 번호 → 사본 번호로 이동을 표시한다.
- 항목 구성이 같고 순서만 다르면 순서만 변경으로 안내한다. 배열을 정렬하거나 집합만 비교해 순서 변경을 지우지 않는다.
- 병력·구조물 1~3번별 현재 → 사본 구성과 동일·순서 이동·새 항목을 표시한다. 바뀌는 버튼은 색으로 강조한다.
- 한글 이름 옆 영문 ID로 이름이 겹치는 병력을 구별한다. 유지·추가·제외는 ID 기준으로 판단한다.
- 실제 전투 HUD와 같은 순서의 현재 단축키를 함께 표시한다. 복구 때 유지되는 현재 기기의 설정을 사용하며 사본의 단축키로 대체하지 않는다.
- 슬롯 선택은 읽기 전용 비교다. 세 덱과 진행도 전체를 복구한다는 안내를 유지하고 선택 슬롯만 복구하는 것으로 오인하지 않게 한다.
- 선택 슬롯을 화면 상태에 보관해 사본 변경·새로고침·가져오기·최종 복구 확인에서도 유지한다. 진행도나 사본 파일에는 쓰지 않는다.
- 공통 비교에 연결해 사본 선택·가져오기·최종 복구 확인에서 같은 구성을 보여 준다. 슬롯 전환은 파일 재조회나 저장을 하지 않는다.
- 버튼 높이 58, 손을 뗄 때 선택, 좁은 폭에서 줄바꿈을 적용했다. 확인창의 기존 Tab·방향키·Esc·키보드 스크롤 연결에 포함한다.
- 기존 캠페인·전적·업적·목표·튜토리얼·도전·닉네임·새 기능 비교와 복구 전 보관·지문 확인·저장 실패 처리를 유지한다.
- README를 갱신하고 오래된 1회차를 아카이브로 옮겨 최근 3회차만 남겼다. 소스로 정규화·슬롯 상태·콜백·단축키 순서·복구 연결을 검토했다.
- 테스트는 추가·수정·실행하지 않았고 게임 실행·렌더링도 하지 않았다. 실제 로드·슬롯 조작·키보드·터치·복구 회귀 검증은 외부 스크립트에 맡긴다.
- 호환성 변경: 없음. RPC 시그니처·세이브·서버 파일 형식과 버전 번호·release.json·CHANGELOG·PatchNotes를 유지했다. Git 명령은 실행하지 않았다.
- 다음 후보: 도전 보관 전투 카드의 전체 덱을 한 번에 검색 조건으로 지정하는 조작, 보관 전투를 다시 저장하지 않고 정리 대상에서 보존하는 흐름, 복구 사본 목록에서 덱 이름·구성으로 원하는 사본을 찾는 검색.

## 2026-10-13 — 오래된 리플레이 정리의 삭제 범위 확인

- 이번 주제: 자동 정리 재시도 전에 삭제할 전투·클립·메모와 보존 범위를 보여 주고, 확인 후 파일 변경 및 부분 실패를 안전하게 처리한다.
- 시작 상태: Git 명령 없이 인덱스·추적 파일 해시와 HEAD 객체의 루트 트리를 비교했다. 미커밋 변경과 미추적 소스·문서는 없었다.
- 최근 3회차와 아카이브의 다음 후보를 읽고 오래된 리플레이 정리의 삭제 범위 안내를 선택했다. 소스 수정 전에 주제를 먼저 기록했다.
- 확인한 문제: 정리 재시도 버튼이 삭제할 파일을 보여 주지 않고 즉시 정리했다. 검색 결과 밖의 전투·클립·메모도 사라질 수 있었다.
- 재시도를 삭제 확인창으로 연결했다. 열기·취소·대상 다시 확인은 파일 저장·삭제·서버 요청을 하지 않는다.
- 전체 보관함 기준임을 명시하고 삭제 대상 수, 보존할 정상 파일 수, 읽기 실패 파일 수를 표시한다.
- 각 대상의 전투 종류·결과·전체 전투 시간·파일명 기준 시각·메모 수와 클립 구간·길이를 보여 준다. 메모·클립 삭제 합계도 안내한다.
- 자동 저장 정리와 수동 확인이 같은 대상 선정 함수를 사용한다. 최근 정상 기록 50개·최근 저장 파일·읽기 실패 파일을 보존하는 기준을 유지한다.
- 대상마다 전투 텍스트 복사를 제공한다. 클립보드 지원·가져오기 크기 한도를 확인하고 다음 복사 전에 게임 밖에 붙여넣도록 안내한다.
- 복사 안내는 목록 밖에 두어 여러 전투를 보관할 때 스크롤을 유지한다. 실제 보관 폴더 경로는 읽기 전용으로 선택할 수 있다.
- 확인창 구성 시 대상 파일의 SHA-256과 읽기 전후 내용을 확인하며, 목록·보관 순서가 달라지면 확정을 잠근다.
- 확정 전 모든 대상의 경로·종류·지문과 보관 목록을 다시 확인한다. 변경을 발견하면 파일을 지우기 전에 대상 다시 확인을 안내한다.
- 삭제는 확인한 목록에만 수행한다. 파일별 삭제 직전에도 지문을 비교하고 폴더·링크·보관 폴더 밖 경로를 거부한다.
- 권한 실패는 재시도할 수 있고 내용 변경은 확정을 잠근다. 일부 삭제 성공 시 실제 삭제 수와 남은 대상 수를 안내하고 새 목록으로 갱신한다.
- 취소는 검색·필터·스크롤을 유지하고 진입 버튼 초점을 복원한다. 정리 후에는 남은 정리 버튼이나 검색칸으로 초점을 옮긴다.
- 기본 초점은 취소다. Tab·방향키 순환, Esc 취소, Page Up/Down·Home/End 스크롤과 버튼 높이 58을 적용하고 닫힌 화면의 콜백을 차단한다.
- README를 갱신하고 오래된 1회차를 아카이브로 옮겼다. 소스로 자동 정리의 반환값·파일 변경·부분 실패·화면 수명·초점 연결을 검토했다.
- 테스트는 추가·수정·실행하지 않았고 게임 실행·렌더링도 하지 않았다. 실제 로드·삭제 보호·키보드·터치 검증은 외부 스크립트에 맡긴다.
- 호환성 변경: 없음. RPC 시그니처·세이브·서버 파일 형식과 버전 번호·release.json·CHANGELOG·PatchNotes를 유지했다. Git 명령은 실행하지 않았다.
- 다음 후보: 복구 사본의 덱별 변경을 한눈에 고르는 흐름, 도전 보관 전투 카드의 전체 덱을 한 번에 검색 조건으로 지정하는 조작, 보관 전투를 다시 저장하지 않고 정리 대상에서 보존하는 흐름.

## 2026-10-13 — 도전 보관 전투의 덱 구성 클릭 검색

- 이번 주제: 도전 보관 전투 카드의 병력·구조물을 눌러 해당 진영의 검색 조건을 바로 추가하고, 키보드·터치 조작과 재생 후 조건 복귀를 유지한다.
- 시작 상태: Git 명령 없이 인덱스·추적 파일 해시와 팩 객체의 HEAD·인덱스 루트 트리를 비교했다. 미커밋 변경과 미추적 파일은 없었다.
- 최근 3회차와 아카이브의 다음 후보를 읽고 남아 있던 덱 구성 클릭 검색을 선택했다. 소스 수정 전에 주제를 로그에 먼저 기록했다.
- 확인한 불편: 카드에서 확인한 병력·구조물을 같은 진영의 검색칸에 다시 입력해야 했다. 덱 미리보기와 검색이 연결되어 있지 않았다.
- 병력 초상화·이름과 구조물 이름을 검색 버튼으로 바꾸고, 내 덱·상대 덱의 출전 순서와 진영 색상을 유지했다.
- 누른 항목은 해당 진영의 검색칸에 추가한다. 전체 검색·다른 덱·결과·클립 조건을 함께 유지한다.
- 추가할 때는 영문 ID를 사용해 마법사·흑마법사처럼 한글 이름이 겹치는 병력을 구분한다. 안내와 툴팁에 이 기준을 표시했다.
- 선택한 항목은 체크와 강조 배경을 보여 주며, 다시 누르면 해당 한글 이름·영문 ID의 정확한 검색어만 해제한다.
- 직접 입력한 한글 이름·대소문자가 다른 영문 ID도 선택 표시에 반영한다. 부분 검색어와 다른 검색어는 자동 해제하지 않는다.
- 공백·탭·개행의 검색어 처리를 기존 검색과 공유한다. 같은 진영·종류의 선택 표시는 모든 카드에 함께 반영한다.
- 검색어 길이 제한을 넘는 추가는 거절하고 안내한다. 기존 검색어를 잘라내거나 조건 일부만 추가하지 않는다.
- 코드로 검색칸을 바꿀 때도 기존 필터 처리로 명시적으로 연결했다. 파일 재조회·리소스 로드·전투 분석을 클릭 경로에 추가하지 않았다.
- 클릭한 카드에 초점을 유지하고 다음 레이아웃에서 선택 항목을 보이게 한다. 조건을 이어서 선택할 때 터치 키보드를 자동으로 열지 않는다.
- 이전 화면의 지연 콜백과 연속 입력의 오래된 스크롤 복원을 화면 수명·회차 값으로 차단한다. 직접 입력할 때의 목록 상단 이동은 유지한다.
- 버튼을 기존 Tab·방향키 순환과 Esc 닫기에 포함한다. 숨겨진 카드의 버튼은 초점 순환에서 제외하며 버튼 높이 58과 손을 뗄 때 선택하는 조작을 적용했다.
- 초기화·새로고침·재생 후 복귀는 기존 진영별 검색 상태를 재사용한다. 선택 표시를 복원하고 카드 버튼의 초점도 파일 경로와 함께 식별한다.
- 숨겨진 카드의 진행 중인 분석 취소·완료된 분석 재사용과 재생·분석 직전 파일 검사를 유지한다. 점수·리플레이·진행도·서버 기록에는 쓰지 않는다.
- README를 갱신하고 이전 1회차를 아카이브로 옮겨 최근 3회차만 남겼다. 소스로 콜백 인자·검색어·선택 표시·초점·화면 수명 연결을 검토했다.
- 테스트는 추가·수정·실행하지 않았고 게임 실행·렌더링도 하지 않았다. 실제 로드·클릭·터치 스크롤·키보드·재생 복귀 검증은 외부 스크립트에 맡긴다.
- 호환성 변경: 없음. RPC 시그니처·세이브·서버 파일 형식을 유지한다. 버전 번호·release.json·CHANGELOG·PatchNotes를 수정하지 않았고 Git 명령은 실행하지 않았다.
