## 2026-10-14 — 전투 스탯의 검색 조건과 읽던 위치 복원

- 이번 주제: 같은 전투에서 스탯 창을 다시 열면 검색·분류·진영·출전 필터와 읽던 위치·초점을 복원하고, 새 전투에서는 초기화한다.
- 시작 상태: Git 명령 없이 인덱스·추적 파일의 원본/LF 해시와 HEAD/인덱스 트리 해시를 직접 비교했다. 미커밋 변경·충돌·미추적 소스·문서가 없어 중단 작업은 없었다.
- 최근 3회차와 아카이브의 다음 후보를 읽고 아직 남아 있던 같은 전투의 스탯 탐색 상태 유지를 선택했다. 소스 수정 전에 이번 주제를 한 줄 먼저 기록했다.
- 확인한 불편: 스탯 창을 닫으면 검색·분류·진영·출전 필터가 초기화되고 설명의 처음으로 돌아가 반복 확인마다 같은 조건을 다시 입력해야 했다.
- 스탯 탐색 상태를 현재 전투의 메모리에 보관한다. 닫기·Esc·화면 교체 전에 조건과 스크롤 위치를 읽고, 다시 열 때 복원한다.
- 마지막 활성 조작의 초점을 이름으로 보관한다. 검색칸에 초점이 있으면 커서 위치도 복원하며 해제된 화면의 노드 참조는 보관하지 않는다.
- 조건 초기화 버튼을 추가했다. 검색·진영·출전 필터를 지우고 병력 분류·맨 위 위치로 돌아간 뒤 검색칸에 초점을 둔다.
- 초기 조건에서는 초기화 버튼을 비활성화한다. 기존 검색 지우기는 검색어만 지우며 분류·진영·출전 필터를 유지한다.
- 복원한 조건으로 카드 표시·구성 개수·성장 수치·초기화 가능 여부를 다시 계산한다. 출전 정보와 수치는 매번 현재 전투에서 새로 읽는다.
- 진영 정보가 없어 비교가 비활성화되면 기본 진영으로 복원한다. 출전 정보 없는 관전에서는 덱 필터를 켜지 않고 기존 미확인 안내를 유지한다.
- 컨테이너 배치·줄바꿈과 초점 추종이 끝난 뒤 스크롤을 복원한다. 내용 높이가 바뀌면 스크롤 컨테이너의 유효 범위로 제한된다.
- 첫 열기에는 지연 복원을 예약하지 않는다. 즉시 닫아도 복원 대기 중인 위치를 덮어쓰지 않으며 삭제·교체된 창의 지연 작업은 중단한다.
- 복원 대기 중 새 조건·Ctrl+F·Tab·페이지 이동·휠·터치·스크롤바 조작이 들어오면 사용자 입력을 우선한다. 자동 정지·확인·요약·결과 창의 초점을 빼앗지 않는다.
- 새 전투·재도전·일일/주간 도전·드래프트·고스트·되감기 실험·새 관전과 온라인 재대전의 기존 전투 초기화 경로에 상태 초기화를 묶었다.
- 새 전투에서는 이전 스탯 창을 닫고 상태 사전을 교체한다. 이전 화면의 참조가 새 전투 상태를 덮어쓰지 않으며 같은 경기의 재접속 화면 재구성에서는 유지한다.
- 초기화 버튼에 놓을 때 실행·터치 높이·Tab 이동을 적용했다. 기존 Esc의 선택 메뉴 우선 닫기·스탯 버튼 복귀·오프라인 정지/재개 경로를 유지한다.
- README를 갱신하고 가장 오래된 1회차를 아카이브로 옮겨 최근 3회차만 남겼다. 소스로 화면 수명·전투 초기화·재접속·입력 우선순위·초점과 상태 참조 경로를 검토했다.
- 테스트는 추가·수정·실행하지 않았고 게임 실행·렌더링도 하지 않았다. 실제 로드·위치/커서 복원·빠른 닫기·터치·재접속·자동 정지·재대전 검증은 외부 스크립트에 맡긴다.
- 호환성 변경: 없음. RPC 시그니처·세이브·서버 파일 형식과 버전 번호·release.json·CHANGELOG·PatchNotes를 유지했다. Git 명령은 실행하지 않았다.
- 다음 후보: 보관함의 선택 검색어를 카드 밖에서도 개별 해제하는 조작, 복구 비교에서 특정 감소 경고의 상세로 바로 이동하는 흐름, 스탯 창의 분류별 읽던 위치를 전환 후 복원하는 흐름.

## 2026-10-14 — 진행도 복구 비교의 변경 항목 필터와 바로가기

- 이번 주제: 복구 비교에서 변경된 항목만 표시하고 항목별 바로가기로 상세를 펼쳐 이동하며, 기존 손실 경고와 비교 상태를 유지한다.
- 시작 상태: Git 명령 없이 인덱스·추적 파일의 원본/LF 해시와 HEAD/인덱스 트리 해시를 직접 비교했다. 미커밋 변경·충돌·미추적 소스·문서가 없어 중단 작업은 없었다.

- 확인한 불편: 변화가 없는 닉네임·튜토리얼 등도 아홉 항목의 요약을 차지했고, 아래쪽 덱·도전 변경을 보려면 긴 비교를 스크롤해야 했다.
- 변경된 항목만 체크를 추가했다. 기본은 기존 전체 표시이며, 변경 없는 항목의 요약·상세를 함께 숨긴다.
- 비교 항목별 변경·동일 표시와 전체 개수를 제공한다. 안내 범위 밖의 과거 기능 ID까지 동일하다는 뜻이 아님을 함께 설명한다.
- 변경 항목별 바로가기를 추가했다. 해당 상세만 펼치고 항목 버튼에 초점을 옮겨 스크롤하며 다른 항목의 접기 상태는 유지한다.

- 덱은 이름·병력·구조물·순서 외에 최근 선택 슬롯만 달라진 경우도 변경이다. 필터와 바로가기는 실제 복구 범위를 바꾸지 않는다.
- 기존 상단 요약·손실 경고와 전체 복구 안내는 필터 밖에 남긴다. 아홉 항목 모두 동일하면 빈 결과 안내와 조건 해제 방법을 표시한다.

## 2026-10-14 — 전투 스탯의 양쪽 출전 덱·성장 수치 비교

- 이번 주제: 스탯 창에서 내 덱·상대 덱·공통/전용 구성을 선택하고 진영별 성장 수치를 비교하며, 온라인은 이미 받은 출전 정보만 사용한다.
- 시작 상태: Git 명령 없이 인덱스·추적 파일의 원본/LF 해시와 HEAD/인덱스 트리 해시를 직접 비교했다. 미커밋 변경·충돌·미추적 소스·문서가 없어 중단 작업은 없었다.
- 최근 3회차·다음 후보와 아카이브 주제를 읽고 양쪽 출전 덱 비교를 선택했다. 소스 수정 전에 이번 주제를 한 줄 먼저 기록했다.
- 확인한 불편: 상대 덱의 병력·구조물만 고르거나 공통·전용 구성을 구분할 수 없었고, 성장 수치는 내 진영 기준으로만 표시됐다.
- 진영 선택에 내 진영·상대 진영·양쪽 비교·공통 출전·내 전용 출전·상대 전용 출전을 추가했다. 관전에서는 블루·레드 기준으로 표시한다.
- 기존 출전 덱만 체크를 내·상대·양쪽에 맞춰 적용한다. 공통·전용 선택은 출전 구성으로 한정하며 기존 체크 상태와 검색어는 유지한다.
- 카드 제목에 양쪽·내·상대 출전 여부를 표시한다. 네크로맨서의 해골은 소환으로 구분하고 양쪽 구성 필터에 포함한다.

- 오프라인 양쪽 덱·성장 단계는 실제 모델에서 읽는다. 캠페인·도전·드래프트·고스트·되감기 실험의 구성을 따로 추정하지 않는다.
- 양쪽 병력 수치가 같으면 하나로 표시하고 다르면 같은 카드에서 진영별로 보여 준다. 미출전 진영의 값은 참고용으로 명시한다.
- 기존 병력 설명 생성 함수·성장 보너스 함수를 재사용한다. 일시적인 지원·장판 효과를 제외한 기준 수치임을 안내하며 밸런스는 바꾸지 않는다.
- 전투 규칙에 오프라인 양쪽 진영의 실제 기지 최대 체력·자원 회복·한도·병력 성장률을 각각 표시한다.
- 온라인 방 상태의 플레이어 순서는 서버 진영 배정 순서와 대조했고, 플레이어는 자기 ID·진영이 맞는 진행 중/종료된 방 정보만 사용한다.
