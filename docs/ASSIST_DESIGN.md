# 보조 서버·계산 돕기 설계

운영자가 직접 관리하는 몇 대의 컴퓨터만 쓰는 구조입니다. 신뢰 문제(서명, 결과 검증 등)는 다루지 않고, 비밀번호나 토큰도 없습니다. 보조 서버든 클라이언트든 접속하면 받아 주고, 대신 가벼운 제한만 둡니다.

## 프로그램 세 가지 (코드는 하나)

| 프로그램 | 실행 | 켜져 있는 시간 | 역할 |
|---|---|---|---|
| 메인 서버 | `CatWar.exe --headless -- --server` (Linux) | 항상 | 로비, 방, 대기열, 전투, 데이터 원본, 작업 목록 |
| 보조 서버 | `StartAssist.cmd` 또는 `CatWar.exe -- --assist` | 몇 시간 | 창이 있는 프로그램. 받을 작업을 고르고 계산 |
| PC 클라이언트 | 게임 설정의 계산 돕기 | 게임 중 | 메뉴 화면에서만, 남는 CPU로 작업 조각을 계산 |

원칙은 둘입니다.

1. **메인 서버는 언제나 혼자서도 모든 일을 할 수 있다.** 도우미가 없으면 같은 작업을 낮은 우선순위(코어의 일부)로 직접 처리합니다. 전투가 많이 돌고 있으면 쉽니다.
2. **누가 일할지는 메인 서버가 정한다.** 도우미는 먼저 연결하고, 일을 달라고 요청하고, 결과를 돌려줄 뿐입니다. 모든 연결은 도우미 쪽에서 메인으로 걸기 때문에 도우미 PC에는 포트포워딩이 필요 없습니다.

## 작업

작업(job)은 독립적인 작은 조각(chunk)들로 나뉩니다. 조각은 `대기 → 임대 → 완료` 중 하나입니다.

- **임대**: 조각을 받은 도우미가 하트비트(2초마다)로 임대를 갱신합니다. 30초 동안 소식이 없으면 조각은 대기로 돌아갑니다.
- **마무리**: 보조 서버의 종료 버튼은 새 조각 받기를 멈추고, 하던 조각을 최대 30초 기다려 결과를 보낸 뒤 작별 인사를 합니다. 못 끝낸 조각은 대기로 돌아가고, 남은 조각을 다른 도우미에게 줄지 메인이 직접 할지는 메인이 정합니다.
- **갑작스러운 종료**: 임대 시간이 지나면 같은 방식으로 회수됩니다. 끝난 조각은 이미 저장되어 있어서 다시 하지 않습니다.
- **메인의 직접 처리**: 그 종류를 할 수 있는 도우미가 없으면 바로, 있으면 조각이 일정 시간 안 팔렸을 때 가져갑니다.

작업 종류와 받을 작업 선택(보조 서버 창의 체크박스)은 같은 이름입니다.

| 종류 | 내용 |
|---|---|
| `balance` | 모든 병력 3종 조합이 캠페인 AI를 상대로 자동 전투를 합니다. 덱과 판수 구간별 조각으로 나뉩니다. |
| `replay` | 리플레이를 다시 계산해 기록과 같은 결과인지 확인합니다. |
| `selftest` | 연결 점검. 작업이 오가는지만 확인합니다. |

결과는 `<상태 폴더>/jobs/result_<번호>.json`에 저장되고, 작업을 요청한 보조 서버 창에도 전달됩니다. 작업 목록은 `jobs/queue.json`에 저장되어 메인 서버를 재시작해도 이어집니다(임대는 무효가 되어 대기로 돌아감).

## 메인 서버가 스스로 올리는 작업

운영자가 요청하지 않아도 메인 서버가 자기 일을 작업으로 만들어 큐에 올립니다. 제출자는 `main`입니다.

- **리플레이 검증**: 공유된 리플레이가 올라올 때마다 `replay` 작업이 생깁니다. 결과는 `jobs/auto.json`의 `audit`에 `ok` 또는 `failed`로 남고, 실패하면 서버 로그에 `REPLAY_AUDIT_FAILED`가 찍힙니다. 한꺼번에 20개까지만 쌓입니다.
- **밸런스 실험은 요청형입니다.** 자동으로 시작하지 않고, 보조 서버 창의 "새 작업 요청"으로만 시작합니다.

이 작업도 같은 규칙으로 처리됩니다. 도우미가 있으면 도우미가 먼저, 없으면 메인이 낮은 우선순위로 직접 합니다.

## 연결 규칙

- 인증은 없습니다. 환경 변수 `CATWAR_ASSIST=off`를 주면 도우미를 아예 받지 않습니다(비상 스위치).
- 제한: 도우미 동시 접속 32대, 한 보조 서버가 열어 둘 수 있는 작업 3개, 대기+진행 조각 합계 6000개. 계산 돕기(클라이언트)는 작업을 요청할 수 없고 일만 합니다.
- 도우미는 `hello(이름, 프로토콜 버전, 받을 작업, 코어 수, 역할)`로 인사하고, 버전이 다르면 거절당합니다.
- 보조 서버와 계산 돕기 클라이언트는 같은 연결 방식을 쓰지만 **계산 돕기는 게임과 별도의 네트워크 연결**을 씁니다. 로비나 전투와 서로 간섭하지 않습니다.

## 단계

1. (이번 단계) 작업 큐, 조각 처리, 하트비트와 회수, 종료 흐름, 보조 서버 창, 계산 돕기, 밸런스 실험 분산
2. 데이터 백업: 보조 서버가 켜질 때와 켜져 있는 동안 메인의 데이터 변경분을 가져가 저장하고, 필요하면 불러오기로 복구합니다. 원본은 항상 메인입니다.
3. CI가 만든 산출물로 서버를 업데이트하고, 도우미에게 마무리를 요청해 한 대씩 순서대로 교체
4. 필요하면 보조 서버에서 실시간 전투를 호스팅
